# 聊天附件与固定版本

聊天消息及远程任务可以携带附件；产品不提供共享目录浏览、文件夹发布或自动文件同步。Agent 使用执行设备上的普通文件工具，跨设备交付通过聊天附件和任务产物完成。

## 权威与交付

原始消息与业务数据库拥有附件归属。发布顺序遵循 [Chat](chat.md)：先保存完整文件并验证内容，再提交引用它的源消息。目录、路径或相同名称不能代替固定内容身份。

附件引用绑定来源设备、内容哈希和大小。发送方保存不可变内容；同一路径的新内容不改变旧消息引用。接收端通过已认证的 iroh 连接向来源请求指定内容，校验大小与哈希后才缓存或交付。传输不发布目录树，也不依赖全网反熵。

客户端 core 管理预览、保存、取消和权限失效，平台只提供展示与目的地能力。撤权立即禁止新的读取并使在途结果失效；不得因为已缓存文件就绕过来源授权。已导出到用户目的地的文件不能收回。断线未知结果不改写原消息或重放业务操作。

## 存储与接入

设备身份与附件只使用当前 iroh 存储，不读取或迁移旧 Synch 数据库、文件树和缓存。旧版本协议不受支持。移除代码不自动清理设备上的历史数据。

设备直连、中继和业务消息同步分别遵循 [设备合同](devices.md) 与 [同步合同](synchronization.md)。

## 验证

固定旧版本读取、哈希或大小不符、撤权后的缓存读取和当前身份持久化需要独立验证。双节点传输测试不代替真实跨网、Android 展示或系统保存验收；测试结果随当前修订报告。
