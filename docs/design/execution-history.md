# 活动与执行历史

活动回答伙伴现在在做什么，历史记录回答实际发生了什么。二者使用真实执行绑定，不能用 Chat ID、作者名字或同一个 Worker 的其他 Session 猜测。

<a id="activity"></a>

## 活动语义

模型为工具调用提供简短 action，描述行为而非推理、原始参数、敏感输入或未经确认的成功。工具注册元数据声明动作和可展示目标，core 生成本地化投影；未知工具使用通用文案，客户端不维护工具名猜测表。

活动元数据随执行事件保存，重连或工具注册变化不重新解释旧记录。未知身份省略目标，不把内部 ID 当人名。并发调用按 invocation 独立保留和结算；思考与工具运行可并存，其他后台工具结束不关闭显式等待。

无输出、实际输出和运行结束分别呈现。实时速度只用计数，估算必须有近似标记，不传递推理正文或伪造供应商未提供的统计。期限、采样与步骤隔离由 core 负责；无变化时停计时和推送，旧步骤输出不能污染新请求。

远端活动经认证 assignment 传递，不创建本地 Worker runtime。断线保留最后可靠状态和可用性，不当作运行结束。头像、文案与气泡动效遵循 [共享设计](interface.md)，点击成员进入其实际执行历史。

桌面可见 Chat 在成员工作时订阅其真实 Session 历史，只投影最近的有界记录。Chat 底部固定高度显示最新一条，可展开查看三条并进入完整历史；记录尚未到达时继续显示实时状态，结束后短暂保留再收起。已接受的 `end` 隔开下一轮活动；切换 Chat 即释放预览观察。预览是只读呈现，不把内部输出写入 Chat 消息源。

## 记录与统计

执行节点持有 append-only 记录。core 按需分页并在 RAM 中关联步骤、调用与结果；不新增客户端历史数据库。累计概览来自权威 snapshot 与后续提交，打开统计或 hover 不拉取全部历史。Session History 页顶部统计当前已加载的模型调用，并明确已报告/总调用数；它与累计概览分开，加载更早记录会扩大显示统计的范围。传递规则见 [状态订阅](state-subscriptions.md)。

- 关联使用确切 ID，结果先到不补造开始或时长。模型身份来自请求开始时的实际配置；缺失模型、缓存报告、首 token 时间或旧快照覆盖保持未知。
- 工具声明的等待时长与观察到的暂停时长分开；即时返回的 wait 回执不终止等待区间，由匹配期限、输入唤醒或中断事实确定。
- 总 tokens 为输入加输出，缓存输入已包含在输入中。累计命中率按有报告的 token 加权并标记覆盖范围；阅读页仅在已报告用量的调用都提供有效缓存数时显示命中率，否则显示未完整报告。无分母时显示未知。上下文替换后不以估计值冒充新的实际输入数。
- 内部 assistant 文本不是另一份聊天消息；模型失败表达为执行错误。远端详情须按认证 owner/assignment 解析执行 Session，不能允许调用方指定任意远端 Session。

## 阅读与聚合

桌面历史页采用可阅读的活动列表：身份、运行环境与模型/用量位于顶部，记录区独立滚动。回复直接显示 Markdown，无额外“输出”标签；折叠预览按实际排版取前五行，展开保留完整正文和绝对时间。Markdown 与代码沿用 Zork 共享渲染器的样式。内部模型文本仍不成为 Chat 消息。

消息输入、工具参数中的公开文案、命令与可读结果在原行内展开，不用通用弹窗替代。详情沿轻描边嵌套于所属行；原始事件 JSON 不作为用户正文。已知会话、Agent 与文件才提供导航，文件内容可在独立阅读器打开。时间与等待沿服务端校准时钟显示，不推测缺失的事实。

连续普通工具与思考记录组成可展开分组；按操作类别去重文件路径，其余按调用计数，并显示失败数。分组包含失败与未知工具，最后一个仍在运行的成员独立显示。输入、回复、等待、对外消息、派工与已接受的结束边界分隔分组；结束边界本身不增加分隔线。展开分组后，成员详情仍可独立开合。

首次进入跟随最新。滚动离开底部、展开详情或定位记录时保留稳定身份和像素偏移；展开后锁定阅读位置，直到明确使用“回到最新”。前插、分组重组、异步正文排版和窗口尺寸改变不得把阅读者送回底部。切换会话恢复原会话的展开与滚动状态。

列表只构建可见行；Markdown、代码高亮与文本排版随内容/尺寸缓存。完成的绝对时间不启动相对时间计时器。加载、失败、重试与分页留在当前面板，后台更新不清空已读内容。窄列下模型独占一行，Token 与缓存并排；长名称、目标及正文保持可读且不越界。

<a id="android"></a>

## Android

从头像或活动进入成员的全页历史，返回恢复原 Chat。成员切换建立新的观察代次；正常聊天不启动详情 loader。阅读保持有界窗口，完整输出仅为所选记录传递，其他行更新不重发全文。

保留前后翻页、回到最新、触屏缩放/平移及非手势替代操作。输入、模型、工具和失败的颜色语义跨端一致。长正文按完整字符边界分块，复制返回完整原文；大系统字体下页脚可滚动，详情支持系统返回与选择。

自绘时间轴提供有界、可访问的记录选择入口。关闭释放 lease，前台恢复先重订阅，再在数据到达后恢复所选详情；不把整页或 Wasm/JNI 状态放进平台恢复存储。

## 验证

覆盖并发同名工具、结果先到、重复/乱序、前插、缺失事实、等待结束、远端绑定、撤权和慢读者恢复。平台另外检查聚合展开、嵌套点击、阅读锚点、完整复制、输入与虚拟化；基准按 [验证规则](../../.agents/skills/zork-validation/SKILL.md) 与实际负载执行，不从 core 微基准推断整页或设备 FPS。
