# 共享界面设计

桌面沿用已确认的 Zork 设计，原始资源的来源和许可保存在 [共享资产](../../crates/zork-ui/assets/interface/README.md)。Android 的触屏几何与系统输入见 [移动端设计](../../apps/android/design.md)。产品归属、权限和操作结果来自 [core](client-core.md)，不在视觉规范再定义 API。

## 视觉与组件

保留暖白表面、墨色文字、品牌橙、动物头像和柔和圆角。颜色、文字角色、密度、间距与轮廓由共享组件持有；页面选语义与尺寸变体，不逐页拼普通 hover、边框和字体参数。新变体需真实重复用途，并同时提供示例。

文字按钮使用胶囊，输入框沿用 12 px 圆角。同等体量的独立卡片、内容面板和模态共用 32 px 平滑圆角，不按是否浮起区分；其他紧凑菜单、小卡片使用 20 px 档，静态选择浮层见下方交互规则，短行与字段保留各自比例。普通图标操作 32 px、紧凑 28 px，Composer 为 24 px 操作和 14 px 图标。平台触控区不直接套桌面尺寸。平滑圆角、描边、裁切和命中同源，约束与退化见 [圆角规则](../../.agents/skills/zork-rounded-corners/SKILL.md)。

正文、说明和辅助信息有清晰角色及可读对比，不能用过浅文字制造层级。业务状态不只靠颜色。PC 客户端与 `zork-design-pc` 共用 Rust 组件，Android 共享语义并保留平台交互；系统授权页遵循其来源。

## 交互状态

- hover/pressed 是瞬态，selected/invalid/busy 有独立语义。选中与错误在 hover/focus 下仍可辨，keyboard focus 使用独立轮廓。
- 普通操作使用中性暖灰反馈，主操作保留其深色或品牌色语义；危险操作使用明确危险配方。pressed 不降低文字/图标整体可读性，也不改变字重、尺寸或内容位置。
- 字段 hover/focus 加强边框，底色稳定；invalid + focus 保留错误及邻近说明。文本链接用文字强调，不突然出现整行按钮底板。
- disabled 阻止反馈与激活；busy 保持几何并按操作语义处理重复输入。按钮禁用不代替 core 的业务校验。
- 热区与反馈范围一致，子元素不抢占根控件 hover。嵌套按钮不触发整行操作，仅局部可点的卡片不整卡亮起。
- 动画从当前呈现状态接续目标，静止/离屏停帧，减少动态效果直接到目标。触屏不能依赖 hover 才发现关键动作。
- 模态、菜单和自绘示例共用焦点域，支持正反 Tab、Esc、系统 Back 与焦点恢复；IME 组合输入不被焦点快捷键误提交。

选择菜单沿用字段的文字、边框和焦点语义。下拉列表与模型选择面板使用独立的暖白静态浮层、16 px（手机 16 dp）普通圆角、细描边、柔和阴影和淡入；填充、描边与阴影共用轮廓，来源不形变或转移材质。浮层按可用空间放在触发器上方或下方，列表过长时在浮层内滚动，不覆盖触发器或撑开表单。单选提交后关闭，多选保持展开直到用户主动关闭；空列表与禁用状态不可展开。触发器说明当前值和展开状态，选项保留选中语义。桌面客户端与 `zork-design-pc` 共用 GPUI 控件，Android 独立实现 Compose 控件和触摸尺寸；两端共享设计元素与 Rust core 的数值、业务合同，不共享 UI 组件。

## 导航与页面

Chat 层级来自 [导航合同](chat.md#navigation)。桌面导航为 32 px 行、共享滑动 hover 和独立的 2×14 px 品牌橙 active 标记；选中不加底色或改变文字。分组留白不截断移动表面，停稳后遵守目标滚动裁剪，内容缩进不改变热区。

侧栏按像素拖动并持久保存，桌面范围 200–420 px；Chat 与设置共用宽度。Agent 消息头显示已知的设备名和模型名，不显示头像；缺少设备或模型事实时只显示已知身份。Composer 随内容增高，无手动拖高柄。页面标题、主操作、分区、字段说明与反馈位置复用组合组件。

桌面 Chat 正文完整显示，不按高度截断，不提供消息折叠设置或独立全文弹窗。跟随新消息时定位到该消息开头；用户浏览历史时保留阅读位置并提示有新消息。

模型设置是独立入口，按供应商展示各设备的 Profile 连接卡片；设备来源、订阅、额度、验证状态和模型数量都显示在卡片中，具体模型进入 Profile 后管理。设备不作为浏览前置选择；同名 Profile 保留各设备的独立连接，编辑写回所选来源；新增连接时才选择保存配置的设备。

表单失败或外部更新保留用户输入，列表更新保留阅读锚点与选择。显示实际对象身份和操作阶段，不从点击、网络断开或动画结束推断成功。

设备名称的展示统一携带 core 提供的连接状态，并复用设备名称与状态组件；文本型菜单和元信息沿用同一状态文案。区分客户端 Mesh 准备状态与目标设备可达性，本机 Station 已在线不能被显示成 Mesh 已就绪。状态更新随连接生命周期传播，不依赖当前打开的页面，也不把状态文字写回设备名称。

## 首次使用

新安装先登录 Zork 账号，再准备本机工作空间与模型，模型可用后直接进入 New Chat。首次欢迎文案留在 New Chat 中央，不另设完成确认按钮。已有可用模型直接跳过配置；需要配置时复用现有模型表单。引导中不提供设备选择或连接，只有一个对话目标时 New Chat 也不显示设备选择条；设备管理保留在日常设置中。

首次使用进度由客户端 core 持久保存。打开浏览器不代表登录成功，创建本机运行环境不代表引导完成；取消、失败和中途退出后从真实账号、运行环境与模型状态恢复。已有工作区不强制重走引导，账号登录不成为既有本地或 Mesh 工作的运行前提。

## 加载与等待

有缓存立即显示；无缓存的列表/对话、局部详情和前翻历史分别在所在区域显示加载。操作提交使用发起按钮内的反馈；文件保存显示实际写入阶段，目的地选择不冒充正在保存。加载失败不能显示为空集合。

应用启动不以设置页充当等待页。已有工作区保留导航与缓存，仅在依赖尚未准备好的设备区域提示状态；尚无可展示工作区时，使用专门的准备或首次使用页面。失败显示原因和重试入口；设置页的返回操作始终回到可显示的对话或首页，不能静默无效。后台恢复完成不覆盖用户等待期间主动选择的页面。

后台同步不遮挡内容。离线 outbox、授权、扫描和人工确认分别表达等待原因，不能统一成永久转圈。运行伙伴使用自己的活动提示，不等同于消息初次加载。

指示器立即占位、延迟出现，避免短操作闪烁；仅可见且活动时调度，静止或离场释放计时。新旧请求按代次隔离，迟到完成不清除当前加载。共享符号与时钟由组件实现维护。

## 附件与只读预览

草稿附件按 core 的添加顺序呈现。桌面收拢纸面与孔口共享真实几何，展开/收拢与附件数量独立：新增先扩孔再出现，删除先退场再收束，连续变化从当前状态接续。hover、固定展开、Esc 和外部点击不清空草稿；离场纸面只用于呈现。

输入框附件操作直接打开系统选择器。缩略图和旋转结果在后台按需缓存，动画帧不解码全文或图片。预览可打开、移除或引用到新草稿，文件权威与固定版本见 [附件合同](shared-files.md#attachments)。

消息图片保持比例，极端长宽比才按既定缩略图规则裁切；文档保留可识别名称/类型及整页预览比例。只读图片使用单层浅暖灰画布，关闭/切换/缩放为直接操作，其余在上下文菜单；不添加无关背景设置或文件信息面板。

关闭预览恢复焦点与阅读位置。复制和另存使用完整原文/字节；截断、编码失败、加载失败与不支持格式分开。代码可高亮、Markdown 可切换源码、SVG 可查看源码；系统首页/封面预览明确不是完整文档浏览或媒体播放。临时预览不修改原快照。

<a id="client-preferences"></a>

## 客户端设置入口

使用客户端默认文字与系统缩放，不另设自定义字号控件。桌面诊断只读取设备信息，复制报告包含版本、系统、检查时间和可达性，去除名称、地址、身份、凭据和 Chat 内容；About 显示实际编译版本与许可。账号入口在首次连接与设置中均可访问，且不依赖 Mesh 就绪，产品账号身份不等于 Mesh 或模型授权。

清空数据必须先说明本机范围、不可撤销及退出行为，再明确确认；取消不修改数据，执行状态由 core 管理，不因关闭页面中断。桌面清空当前客户端及其内置节点，保留独立 Station 和其他设备；先停止节点，待旧进程及写入者退出后完整移除存储，再以空白状态重启，中断恢复先于任何新存储打开。手机使用系统应用数据清理，退出后由用户重新打开，不删除电脑上的 Profile 或 Agent。

## 手机端职责

手机连接已有设备、创建和参与 Chat，并管理模型连接，不托管 Station。接入使用扫码/粘贴电脑邀请；生成邀请、批准其他设备和节点接入命令属于电脑端。

Skill 按 Agent 查看，服务按设备查看，MCP 展示获准的连接与定义；资源入口不扩大管理或执行权限。外观和通知管理本手机体验，保留移动端返回、触控和系统输入行为，不复制电脑节点运行设置或空占位页。

通知见 [系统通知](notifications.md)，模型与账号规则见 [模型连接](model-connections.md)。

## 组件展台

Playground 用真实共享组件表达和验证交互；外壳本身也必须全部由组件库组成。缺少能力时先补共享组件，页面不复制控件、布局配方或装饰绘制。业务示例使用 core fixture，不能实现另一套规则。

复用指调用同一个完整组件，包含材料表面、目标切换、展开与退场、输入和焦点生命周期；页面传入内容、参数和回调。把另写的控件放进组件库、另加一组外壳专用 API，或只共享几何、内部按钮和正文，都不算完成。组件能力不足时完善原组件，或把原示例中的实现提取为公共组件，并让原示例立即改为调用它。

目录、示例工作区和参数面板各有职责：目录先区分基础组件与业务组件，再按用途选择家族；并发测试单独进入。项目使用的所有 UI 控件都必须有共享实现和组件库展示，包括基础控件、状态指示与完整业务组合。新增或修改控件时，同步补齐实际使用的状态和交互示例。Playground 传 mock 参数，项目传真实参数，双方调用同一个完整组件；视觉、交互、材料、输入、焦点及退场生命周期没有演示版与项目版之分。mock 适配提供同一参数和事件合同，不在示例中另拼控件，也不通过示例专用分支改变其行为。

基础组件目录参考 Radix 的职责与行为合同，外观和动效沿用 Zork 的共享组件与设计规则。已有源码、独立演示和完整键盘/可访问性合同是不同的覆盖层级，不能凭外观或业务组合认定组件齐全。核对结果随任务保存，不在设计文档维护实现清单。

示例用简短说明和真实操作展示状态，参数调整材料或场景。示例默认在连续的白色无框画布中按标题和间距分组，不统一套卡片；组件保留自身表面。同组简短状态与变体合并为共享分段选择，不排列多个独立按钮；选项过多或文字较长、无法保持标准热区时使用选择器。状态选择与整页调参分别布局。

宽窗口显示独立滚动的目录和参数栏；空间不足时使用共享模态面板，不压缩文字或整体缩放画面。断点由真实示例最小宽度决定，工作区保持阅读密度和必要留白。

全部外壳使用共享文字角色、标准热区和平滑几何。无框预览按实际内容定高，保留矩形视口约束；组件自身的内容沿各自轮廓裁切。静态布局不启动物理模拟，不能用只有背景的圆角容器假装裁切内部画布。系统遮暗层的开孔也消费同一几何。

目录切换保留稳定示例实体与输入状态，停止连续演示；只有显式重置才恢复材料默认值。参数上下限禁用，不循环跳回。采样期间锁定会改变条件的操作，结束恢复；无记录不能复制结果。菜单与模态支持键盘、滚动、IME 和返回焦点。液态控件的材料、触发器和退场遵守下方合同；产品窗口弹窗采用 [PlainDialog](codex-plain-motion.md#plain-dialogs) 的面板与淡入配方。

## 液态表面合同

### 材料与控件身份

液态表达同一材料在状态之间的连续变化。按钮按压、滑动高亮、面板展开分别使用各自的材料运动配方。完整控件共享材料、内容、输入与焦点实现，应用和展台只组合它们。

从按钮打开浮窗或模态时，来源材料与面板材料共同参与牵动、连接、分离和重新融合。原按钮持续存在；面板从实际来源分离，关闭时回到当前来源。分离之后仍保留双方的材料身份和运动状态，快速反向直接接续当前形状与速度。

控件身份、材料身份和绘制层级分别管理：控件身份维持输入、内容与返回焦点；材料身份维持几何、速度与成员关系；绘制层级决定遮挡和裁切。原控件及其绘制身份保持唯一，开合不切换来源的显隐。页面与动画引用同一份来源绘制，每帧只合成一次；切层随整帧提交，不依赖退出回调恢复按钮。绘制引用不复制控件实例、事件处理器、焦点或可变状态。

<a id="liquid-presentation"></a>

### 呈现与后端

完整组件提交实测目标、原控件内容和视觉配方，并拥有交互、焦点与退出语义。共享数值层 `zork-liquid` 只消费目标、经过时间及可见性，输出材料运动与轮廓，不持有窗口、控件或纹理。平台呈现适配负责内容绑定、绘制记录失效与播放交接；渲染后端负责内容缓存、路径掩码、变换、透明度及资源回收。业务职责仍遵循 [core/UI 边界](client-core.md)。

应用接入以完整组件和共享数值场景为边界。优化几何、布局复用、缓存或 GPU 提交时保留调用方的内容、目标及事件合同，不要求页面管理纹理、路径缓存或绘制快照。批量传输只维护当前一版，变更时同步更新 Rust 编码、JNI 消费端与合同测试，不保留未使用的版本分支；字段布局以 [场景源码](../../crates/zork-liquid/src/scene.rs) 为准。材料进度、内容显露和遮暗显露是独立输出，平台不从其中一个推算另外两个。

弹窗的标题、正文和操作组成一份整体内容快照，液态表面独立负责形变与裁切，不按文字或控件类型拆分合成层。材料运动与内容显露分别推进，普通动画帧复用按目标宽度布局的内容，只更新当前轮廓和合成参数。遮暗层、来源几何、填充、描边与内容缩放来自组件配方；正常绘制和缓存播放消费同一份有序绘制描述。静态表面可只使用几何，流式内容、编辑光标与滚动区域按其更新频率独立失效，不要求所有隐藏内容预先常驻。

| 变化                                 | 呈现责任                                             |
| ------------------------------------ | ---------------------------------------------------- |
| 位置、轮廓或显露进度                 | 更新几何、掩码与合成，复用有效内容记录               |
| 内容、目标宽度、字体、样式或内部滚动 | 重新布局或记录受影响内容，沿当前材料状态重定目标     |
| 窗口、DPR、设备或祖先裁切/变换       | 重新核对坐标、资源与输入版本，失效时返回正常组件流程 |

后端报告能力与本帧准入结果，组件不依据平台名称或自行打开开关推测支持。缓存预算按实际像素字节计算，覆盖播放引用的资源，并有淘汰及销毁路径。同帧中的前后绘制版本使用独立纹理槽，重复合成和正在记录的嵌套层均计入预算。超预算或不支持的嵌套效果回到普通绘制，保持相同内容、轮廓裁切和输入行为，不重置材料。优先按有效内容区域分配，资源策略不成为组件 API。

平台按 GPU 完成信号限制在途绘制，合并等待期间的帧请求，并在恢复时处理当前输入和窗口尺寸。完成回调不为静止窗口制造新帧；完成失败与窗口销毁仍须释放等待和资源。

内容缓存可用与跳过组件重建分别判定。只有布局、输入和绘制记录版本相容时才允许仅重绘播放；真实输入或内容失效优先回到正常流程。展开结束时提交准确终态；布局和输入仍有效时直接停帧，不为结束动画强制重建宿主。绘制换层发生在操作开始的那一帧：复制实际已呈现的静态画面到目标层，切换前后像素一致，再在目标层推进动画。只重绘播放后的实际画面也是复制来源，不能退回上次布局帧。不能安全独立替换的嵌套或重叠区域由共同父层或普通绘制处理。关闭、取消与销毁撤销旧播放，静止及隐藏不持续申请帧。

### 页面与浮层

| 绘制归属 | 拥有的内容                       | 约束                                                                             |
| -------- | -------------------------------- | -------------------------------------------------------------------------------- |
| 页面     | 唯一控件实例、布局锚点及输入身份 | 始终使用实际页面布局；交出动画绘制时避免原位重复绘制，保留原控件与焦点           |
| 模态遮罩 | 页面遮暗与模态外部输入拦截       | 位于页面之上、模态面板之下，覆盖原按钮；按组件语义决定外部点击是否关闭           |
| 浮层     | 面板材料、正文、操作及面板描边   | 消费实际来源几何和返回焦点；动画层可以播放来源绘制结果，不建立第二个来源命中区域 |

目标在哪一层，整个动效就在哪一层播放。打开模态时立即切到模态层，以当前底层绘制结果作为初态；关闭时立即把模态的静态画面交给来源所在层，在该层收回。连接处使用同一材料模型生成的完整连续几何，不能按来源与目标的控件层级切割填充或描边。静态来源和目标的绘制结果随内容、布局或样式变化失效；普通开合复用它们，仅更新材料轮廓、裁剪和合成参数。输入仍由原控件处理，绘制交接不能重复注册事件或改变返回焦点。

面板与原按钮重叠时，面板的实色材料和内容按真实轮廓遮住下方按钮。填充、内容裁切和描边消费同一几何；面板内容在其填充之后绘制，描边最后绘制。

### 开合、滚动与退出

| 阶段     | 来源按钮                                 | 浮层材料与交互                                                                     |
| -------- | ---------------------------------------- | ---------------------------------------------------------------------------------- |
| 关闭     | 正常绘制，保留自身 hover、按压和焦点反馈 | 画面与输入区域只保留原按钮，浮层停止绘制与帧调度                                   |
| 打开     | 留在页面，参与材料牵动                   | 从实测来源连接、拉伸并分离；面板内容在可容纳的轮廓中显露，焦点按组件语义移入       |
| 展开     | 继续服从页面布局和裁切                   | 面板保持实色及原有材料身份；实际内容决定尺寸，窗口或锚点布局决定位置               |
| 关闭过程 | 留在页面的当前位置                       | 面板向按钮收回；文字与控件随收缩的轮廓逐渐裁去，不可见的控件停止接收点击与键盘输入 |
| 回收完成 | 继续正常绘制，焦点回到来源               | 画面只剩原按钮，浮层结束绘制、命中与帧调度                                         |

关闭是一段连续的收回过程：来源层播放弹窗的静态绘制记录，面板缩回按钮，内容按当前轮廓裁切，保持原按钮内容完整。退出即撤销弹窗内容的输入资格；静态画面不重建可交互的弹窗，也不等待融合结束才换层。有来源的液态面板在此过程中保持实色。模态在实际材料展开过半时开始淡入遮暗背景，来源按钮随页面一起被遮暗；关闭时背景立即开始淡出，材料同时沿当前状态收回。已展开后的内容或尺寸变化不重新隐藏背景，快速反向接续当前透明度。Tooltip 和 hover 使用各自的显隐配方。

动画结束按剩余可见形变与运动量共同判断，保留目标附近仍可见的回弹，不在高速穿过目标时截停，也不等待浮点数达到数学静止。达到亚像素范围后落到精确终态并停止调度。背景显露的时机独立于数值尾部收敛，不以所有粒子完全静止作为淡入条件。

锚定浮窗的位置由“按钮在滚动内容中的位置 + 共同的滚动位移 + 浮窗相对按钮的偏移”确定。按钮与浮窗使用同一帧的布局结果：在放置偏移不变时，页面向上滚动 20 px，两者同帧向上移动 20 px。浮窗的绘制层级独立，定位仍使用这份共享坐标；滚动位移即时生效，局部形变继续沿原有状态运动。

窗口边缘处的放置方向和可用尺寸由布局统一决定；开合中滚动也使用相同坐标关系。固定模态在模态层按窗口定位；关闭时以按钮所在层为坐标基准，同帧应用该层的滚动或布局位移，局部形变继续沿当前状态收回。快速反向时复制当前呈现画面并转换坐标基准，保留材料速度。仅位置变化复用轮廓与细分缓存。

来源的原位呈现服从页面裁切，复制的来源内容保留其可见范围；完全离屏的锚定浮窗停止绘制和调度，返回时采用当前布局。已关闭的浮层保持关闭。后台停止推进动画，恢复时接续当前状态；减少动态效果直接呈现目标状态。

同一来源反向时保留当前材料；不同来源激活时分别绑定实际原点与返回焦点。模态内更换内容保持面板材料和原始返回来源，同时将焦点放入新的内容范围；来源离屏不销毁其焦点身份。

### 滑动反馈与菜单转移

同一组 hover 使用一个持续存在的材料，在行之间连续移动并调整尺寸；移出后在最后位置淡出。停稳只停止帧调度，下一次换目标仍从当前状态接续。选中指示器独立维护。

同一菜单组切换时，已展开面板保留材料身份并转移到新的触发位置，同时更新内容和尺寸。在空间允许时保持展开方向，避免盖住触发器。常驻 hover、选中标记与临时浮层分别管理其存续与显隐。

hover、高亮指示器和菜单转移以统一的基准移动速度决定时长。距离较远时可小幅提高速度，但移动时间仍随距离增加，并在正常界面距离内保持利落。起停使用短促缓动；中途改变目标时保留当前位置与速度，再按剩余距离继续。位移节奏与轮廓形变分别管理，形变沿用共享材料模型。

### 表面、内容与视觉配方

主操作文字和图标按钮使用品牌橙色底与白色内容，hover/pressed 沿用品牌色配方，禁用时使用中性底色。普通文字按钮默认描边、内部跟随父表面；Soft 使用中性浅色底，Ghost 默认无底色和边框。菜单、提示浮层、模态和从触发器展开的面板均用细描边，不透明浮层保留底色以遮住下方内容。触发器在展开、分离、融合和退场全过程保持原有描边。所有界面边框共用 0.5 px 逻辑线宽，焦点与错误通过颜色区分，不加粗。界面不使用投影；填充、描边和状态反馈沿同一液态几何运动。

普通图标按钮默认无边框、无背景。会分离出液态面板的图标按钮在 hover 或展开时显示描边；直接执行操作的普通图标按钮在 hover/pressed 时使用中性背景色。分段单选保留一个外框，选中段使用主题色填充；文字排版固定，当前液态轮廓覆盖的部分为白色，未覆盖的部分为墨色，同一个字可同时呈现两种颜色。无框单选保留圆点标记，不给每个选项另加外框。动物头像使用透明肖像，选择时不套背景框。卡片、Composer 和开关状态用纯色填充，导航标记及容器内部的 hover/pressed 用色块反馈。附件列表等容器内的操作行保持平面，复用共享滑动 hover；行末删除/收拢操作在悬停或键盘聚焦时显现，点击子操作不激活整行。颜色与线宽复用共享语义配方，禁用、焦点与错误保留各自反馈。

复选框的选中与混合态只用实色底和清晰标记，不叠加边框；键盘焦点仍提供独立可辨识反馈。

短文字 Tooltip 按内容与紧凑内边距定宽，详情卡片独立使用适合其内容的宽度。状态提示的图标、正文和行末操作垂直居中，加载符号复用共享指示器，不能用字体字符代替。

液态作用于完整表面，文字和图标保持清晰。组件提交目标位姿，由同一引擎处理位置、尺寸、局部形变及成员分离/融合。

跨平台材料、轮廓、描边与视觉转场由 `zork-liquid` 维护；GPUI 和 Android 分别适配绘制、原生输入与窗口。Android 每个可见宿主统一推进场景，批量传入变化目标，只更新变化的路径或位置；静止挂起，后台停止调度，恢复不补算后台经过的时间。视觉帧与业务同步分开，业务仍由客户端 core 负责。

额外的弹性位移与速度引起的圆角增量按逻辑像素控制，大、小控件保持接近的回弹幅度，不随尺寸或移动距离等比例放大。矩形面板在高速展开中保留边线，不能圆化到短边的一半。位移、尺寸过冲和锚点牵动共用这一约束，快速反向保留当前状态与速度；模态的正文和操作不能因回弹被带出可见窗口。

菜单触发器按当前文字、图标和标准内边距定宽，选项面板独立按最长选项、最小宽度与紧凑行距计算。展开和收回时保留终态文字布局，仅裁剪可见内容，不因临时轮廓变小而增加省略号或重新换行；选项底色与文字分别按当前轮廓裁剪，不能用一块矩形裁切区切掉所有选项的圆角。选中态使用对勾或描边，底色用于悬停和按压。

沿容器外轮廓排列的内层底色，圆角与边距一起计算：内圆角由当前外圆角减去同侧内边距推导，并受内层短边半径上限约束；短行容纳不下对应转角时，共享布局增加必要内缩，避免悬停底色被父轮廓切平。填充与边框沿共同的几何配方变化，避免独立圆角造成转角处忽宽忽窄。

卡片、预览边界和内容面板默认用实际内容布局决定高度；调用者提供宽度、位置和内容，不传预估高度。内容增删与换行经共享测量重定目标并接续动画。模态的视口上限仅负责限制高度并启用内部滚动。各内容区分别接受轮廓裁切，不能把转角所需的最保守内缩应用到整块正文。末项之后保留与同层侧边一致的内边距；动效画布的预留空间不能额外叠加到卡片底部。

固定模拟步长使动画速度独立于显示调度。同版本、完整初态与输入序列应可复现；按真实尺寸计算，不能只缩放固定动画。[reference12](../../crates/zork-liquid/src/fixtures/reference12.json) 保留原始模型的固定对照，新增回弹约束单独验证，不改写原始输入来掩盖行为差异。数值与算法由共享实现维护。

当前几何合同为平滑矩形与圆形，静态表面可只使用几何。填充、描边、焦点、轮廓约束与精确命中同源；布局槽和业务可用性不随微小形变漂移。未验证参数或轮廓失败有明确回退，不能中断整页。

实色父背景遮盖仅适用于相应不透明表面，透明/图像背景需要真实路径掩码。材料/尺寸变化使缓存正确失效，仅位置变化复用几何；静止、离屏和减少动态效果遵循 [圆角与绘制规则](../../.agents/skills/zork-rounded-corners/SKILL.md)。

按压反馈和业务提交分开：动作在实际激活时提交，回弹独立结束。连续点击、拖出返回、焦点或禁用改变仍连续，键盘与 IME 保留原输入模型。

## Composer 演示

复用真实输入、附件几何与 core Controller。只有 core 接受提交后才产生有界临时发送气泡；它不证明消息已送达，停止或拒绝不产生飞行气泡。按钮来源与输入底板来源分别保留材料连续性，离场回收。

演示等待、结果和文件预览明确属于本地 fixture。平台只适配选取和输入；选择文件名不代表已读取/上传字节，临时视觉元素不成为业务列表。
