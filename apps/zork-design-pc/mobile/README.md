# Zork 移动端设计

[移动端设计规范](design-spec.md) 是当前交互约束；[桌面与移动差异](../docs/10-mobile.md) 说明平台职责。原生 `zork-design-pc` 可浏览这些文档与[三屏概念图](zork-mobile-v1.png)。最初概念图不代表后续修订的最终行为。

早期 HTML 原型、修订记录、自包含 SVG 快照和 DOM 检查保存在 [归档](../archive/mobile-prototype/README.md)，仅用于追溯。实际 Android 触摸、系统键盘、选择手柄和原生视觉仍需按当前应用验证。

[素材映射](asset-map.json)、[移动端 tokens](../tokens/mobile-tokens.json) 与[机器可读清单](manifest.json) 保留来源和状态；原型中的 SVG 副本不取代共享品牌素材的源文件。
