Zork 移动端设计规范

版本：nav7 / 2026-09-06。范围：移动端对话导航、群聊、设备及其 Agent / 模型连接设置。本规范整理当前用户确认的交互要求；原型尚未完成实际手机和浏览器截图验收。

产品关系与导航

  • 设备 → Leader → Task。Task 是群聊，Leader 是长期协作范围。
  • 导航与对话分别占一屏；点名称进入对话，Leader 右侧独立按钮展开/收起其任务。
  • Task 不使用重复图标或层级竖线，名称与 Leader 名称对齐；不加入消息摘要、未读筛选、搜索或手动创建 Task。
  • 移动端聊天列表没有持续 active / selected 状态，不突出上次打开的对话。未读通过计数表达，不改变字重。
  • 返回对话列表保留滚动位置；不同对话分别保留草稿、评论、附件和阅读位置。
  • 底部“添加设备”“设置”采用两个并排、等宽的触摸入口。

触摸与状态背景

桌面 hover 对应移动端按压反馈；移动端不依赖 hover，也不把悬停后的样式作为常驻状态。

规则 当前实现
导航行高 48px；常用独立控件至少 44px 点击区域
导航圆角 6px
相邻导航背景间隔 2px
列表外侧留白 10px
行内内容留白 14px；层级缩进只作用于内容
按压背景 oklch(94.8% .005 85)，沿用桌面 hover token
持续选中背景 聊天列表不用；真正需要选项选择的控件才使用选中语义
字重 按压、焦点、未读变化均不引起字重变化

同一层列表的背景和命中区域必须从共同左边界延伸到共同右边界，不随图标、文字缩进或内部按钮缩窄。Leader 名称区域和展开箭头是两个操作，但只有整行容器绘制状态背景，内部按钮始终透明。

设置行同样整行命中：分组容器不放横向 padding，内容留白移到每行内部。设备、Agent、模型连接入口共享这一规则。分隔线可以内缩，点击区域不内缩。

按压状态只存在于手指按住时。抬手、滑动超过触摸阈值、系统取消、滚动或页面失焦均清除。键盘可用背景反馈显示焦点；不增加控件 outline。

群聊与评论

  • 顶部显示返回、实际成员头像、所属设备。头像保持个体身份，不把品牌吉祥物作为所有 Agent 的头像。
  • 自己的消息无头像或“你”标签；气泡贴合内容，时间在外。Agent 消息显示头像、姓名、设备和时间。
  • 文件在消息流中预览/下载，输入区可添加附件。
  • 不设置固定回复按钮、点赞、角色徽标或 @ 分派入口。
  • 选中消息片段后出现评论入口。评论先积累到输入区上方，可继续添加、编辑、移除，最后与正文一起发送，也可仅发送评论。
  • 输入框自动增高，不提供拖拽尺寸手柄。Enter 换行，点击发送按钮提交。
  • 内容区域独立滚动；页头与输入区域固定在应用内，输入区随可见视口适配系统键盘。

设备设置与返回来源

聊天顶部的设备入口使用 6px 圆角、左右各 10px 留白、至少 44px 高度，以及统一按压色。

从聊天进入设备设置时，设备页提供“返回对话”，直接回到原 Task 或 Leader 对话，保留草稿与阅读位置。进入设备的 Agent / 模型子页后，这一来源也不丢失。从设置列表进入设备页则返回设置列表。不要把所有返回动作固定成跳转设置首页。

设置区分客户端和设备；不虚构未规划的客户端偏好。设备页包含 Gateway 版本与检查更新、设备自身的运行偏好、Agent 与模型连接。此处后台运行/登录后启动针对远端设备，不代表手机支持后台运行 Agent。

模型连接与 Agent

  • 每个连接归属一台设备；Agent 只选择本设备连接下的模型。
  • 添加连接先选订阅账号 / API 接入，再选供应商与认证方式。
  • 添加时不注入程序中的预设模型；模型在连接详情获取或手动添加。
  • 原型不收集真实密钥、不执行 OAuth；演示连接标记未验证。
  • 添加设备保留手动接入说明和 Leader 协助。选 Leader 时只准备请求草稿，不自动发送或生成真实邀请。

视觉资源

使用炭墨、暖白、少量柿橙，以及已有 SVG 标识和动物头像。拉丁字符与数字使用 Inter，中文使用系统无衬线字体。正文约 15–16px，辅助文字约 11–13px。新字标探索由品牌任务管理；移动原型当前保留 Zork 文本标识，不代表已接入品牌任务后来新增的字标或动画。

原型的 assets/ 保留自包含副本及字体许可证，便于独立打开；后续统一品牌资源时应追踪源文件，避免把副本当成另一套品牌资产。

当前验证与原型边界

DOM 事件检查通过：导航与折叠、对话草稿隔离、评论合并发送、文本转义、设备设置隔离、连接/模型配置、重复模型校验、Agent 模型选择、整行按压与取消，以及聊天 → 设备 → 子页 → 原对话的草稿/阅读位置恢复。静态资源 HTTP 检查通过。

原型不连接真实 Agent、模型或设备，发送与配置仅改变页面内存，刷新后重置。检查更新与获取模型会说明未连接服务，不伪造成功结果。

内置浏览器不可用，Chrome 控制接口超时；没有完成浏览器截图对照、实际触摸设备及系统键盘测试，视觉 QA 保持 blocked。用户提供的截图用于定位并修正反馈问题，不冒充修订后的截图验收。
