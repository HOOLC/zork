# zork 群聊式 HTML 样稿

入口 ../gui.html，仅 mini1 本地预览。未连接真实 Agent、模型或设备，不修改 zork-gui 产品源码，不部署到 ChatGPT。

## 对话

- 设备 → Leader 长期范围 → Task 群聊；未读在所属范围优先。
- Leader 28px 行高、个体头像；折叠按钮处于整行悬停背景内。设备点击整行展开，无额外箭头。Leader 不相对设备缩进。
- Task 无重复图标、无竖向层级线；文字与 Leader 名称对齐，背景与相邻行保留 2px 间隔。
- 顶部仅显示 Agent 成员头像和所在设备；点击头像查看成员。无群聊标题、搜索或文件工具栏。
- 不显示最新消息预览、角色标签、点赞、未读 tab，也不提供手动建 Task、拉人、改名、置顶或 @ 分派。
- 自己的消息没有头像或姓名，气泡贴合内容，时间在框外。所有消息均无固定回复按钮。
- 选中一条消息正文内的文字后，附近自动出现评论输入框。添加后暂存在主输入框上方，支持连续多次评论、编辑、移除；最后与主输入框内容一起发送为一条消息，也可仅发送评论。评论按对话保留，切换对话不丢失，保留原有文字草稿。
- 文件仍可在消息中预览、下载，也可从输入框补充文件。

## 设置与接入

设置采用独立左侧导航与右侧内容，明确分开客户端设置与设备设置。客户端目前无专属设置；设备设置直接列出全部设备，每台设备下直接列 Agent、模型连接两个子项，不再在右侧使用 tab。点击设备名称进入设备本身的设置，查看 Station 示例版本、检查更新与后台运行 / 登录后启动偏好。数据与新增表单始终绑定当前设备。字号固定 13px，显示时间，Enter 发送，Shift Enter 换行。

左下角是添加设备、设置。添加设备弹窗提供一排 Leader 头像，选择哪个就进入哪个 Leader 对话准备接入草稿（不自动发送）。手动获取和复制命令仍保留。命令格式依据仓库 docs/design/devices.md；样稿只展示包含 <invitation> 的模板，不创建真实邀请。

每台设备的“模型连接”管理 Profile：先选择订阅账号 / API 接入，再通过带图标的紧凑下拉选择支持该方式的供应商。添加表单只建立连接；兼容接口额外填写地址，模型 ID 与容量移到连接详情。

新连接不自动填入程序模板模型。保存后进入连接详情，可获取或手动添加模型；本地样稿点击获取时明确提示未连接真实节点，不会假装发现可用模型。手动模型容量校验输出不大于上下文。没有模型的 Profile 显示“待配置模型”，Agent 编辑也有明确提示。

Agent 编辑先选择本设备的 Profile，再选择其中的模型；不同 Profile / 设备的模型不能混选。连接列表显示提供商、接入方式与模型数量，可查看所含模型。

来源为 crates/zork-gui/src/desktop/profiles.rs、desktop/agents.rs 和 crates/profile/src/providers/。profiles.js 保存当前产品目录的样稿快照（8 个提供商），不是实时模型能力或价格推荐。

所有 Profile 仍仅保留页面内存、标记未验证。API Key 不存入记录或 localStorage。OAuth 只展示设备码 / 浏览器回调流程，可明确点击“模拟完成登录”，没有实际请求授权或验证凭据。

## 实现与验证

当前加载 chat.js、profiles.js、settings.js、selection-reply.js 以及对应 CSS 和 tokens.css / density.css；旧 app.js / app.css 不再加载。统一复用已确认的原创 SVG 与头像。

构建与 JavaScript 语法检查通过。DOM 烟雾验证包括层级导航、草稿、消息转义、多条选中片段评论暂存、编辑、跨对话保留及一次发送、Leader 接入路由、手动命令与复制、客户端 / 设备设置、设备隔离的模型连接与 Agent 配置。未声称完成浏览器截图验收。

设置分类参考官方说明 https://learn.chatgpt.com/docs/reference/settings ，本机 Codex 窗口不允许自动读取，未做像素复刻。

设备设置截图复查：修复导航图标被 flex:1 拉伸的问题，固定图标 16px、只让名称伸展；配置列表行高 44px，去掉外层卡片和重复设置文案；在线状态与 Leader 协助头像靠近对应文字。基于用户提交的当前截图，修订后未自动截图。

右侧配置列表再次按截图收紧：Agent 名称与模型连接改为同一行两列（36px 行高），未配置状态不再单独占一行；角色分组不加横线，开发设备说明移入页头，Leader 协助与说明保持邻近。

控件不显示 outline 或头像外圈，键盘聚焦通过背景色反馈。

Profile 提供商选项与连接列表配套品牌 SVG（Lobe Icons static-svg 1.95.0，MIT，来源与许可见 provider-icons/）；兼容接口使用原创 24×24 / 1.7 描边代码符号。

设备页版本与运行偏好都是本地演示状态，检查更新提示尚未连接真实节点，未实现或暗示一键自动升级。实际产品 docs/guides/native-releases.md 明确完整版本升级当前仍为手动流程。添加设备命令模板也已按最新 docs/design/devices.md 改用固定 GitHub Release 的原生 install.sh，未执行安装。

所有层级导航的 hover / 选中背景保持父容器全宽，缩进只使用行内 padding（设置设备子项、Task 与设备详情里的任务行一致）。

导航样式集中在最后加载的 navigation.css：设备、Leader、Task、客户端设置和设备子项统一 30px 行高、6px 圆角及 hover / 选中背景。连接方式选项也采用相同行高与等宽点击区域。

active 状态统一为 selected 背景与正文色，字重保持不变；移除对话列表独有的橙色竖条。

未读也不改变字体粗细，避免点开未读项时因清除未读状态而发生字宽变化；未读由计数标记区分。

底部添加设备 / 设置入口也使用统一导航尺寸：30px 行高、12px 文字、同宽背景和相同 hover，避免遗漏在旧 footer 样式中。

最终实现补充：侧栏像素宽度可拖拽并持久保存，范围 200–420px；聊天头高 44px，成员头像与消息头像使用同一列边距；输入框随内容增长到 160px 后滚动，不显示拖拽把手。Zork 名称采用 gui/brand/zork-wordmark.svg 独立路径字标，品牌图标与导航图标对齐。
