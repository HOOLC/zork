## 原缺口的完成情况

| 原缺口 | 已补内容 |
| --- | --- |
| 模型接口协议菜单 | 供应商图标、选中状态、展开菜单、键盘移动与关闭 |
| Agent 连接与模型菜单 | 触发器和选项的供应商身份、连接与模型联动 |
| 模型添加/编辑 | 模型 ID、接口协议、容量、可用及默认推理级别、校验、保存与取消 |
| Agent 添加/编辑 | 角色、名称、头像、职责与偏好、Worker 授权、模型配置与头像分别保存 |
| 会话执行历史 | 真实时间轴、用量与缓存、运行/完成/失败、事件展开、缩放与选择 |
| 客户端账号 | 未登录、登录中、失败、已登录；取消、重新验证、退出与身份复制 |
| 设备设置 | 运行、停止、加载、错误；版本刷新、后台运行与系统登录启动联动 |
| 设备连接 | 已连接、空列表、手动配对与管理权限；身份复制、刷新、移除 |
| 添加设备 | Leader 入口、生成/复制/撤销加入命令、加载、错误与过期重试 |
| 公共组件收录 | 通用弹窗、头像选择、历史事件、评论浮层与队列、附件、状态提示 |

公共 Switch 包含关闭、开启、禁用关闭、禁用开启、焦点共 5 个状态。按钮统一为 32 px；供应商身份在连接、模型、协议及 Agent 选择器中复用。

## 来源与复用

当前参考实现位于 `src/reference/`，是根据本轮补齐范围更新的 React 设计稿；旧 HTML 原型仍保留为历史材料。它们有不同的来源标记，当前设计稿不冒充早期原稿。

`crates/zork-ui/assets/stories/page-fixture.json` 同时提供两侧初始数据。React 的颜色与基础尺寸从公共 GPUI 常量读取。原生截图记录实际 Metal 输出，参考截图记录实际浏览器输出；每次导出保留来源文件哈希、参数与裁切范围。

原生应用、基础组件示例及 Web 页面共用 `crates/zork-ui/` 的公开组件。该包不依赖 Station、网络服务或应用数据库。账号、设备、组网、弹窗、历史事件行、评论和附件的正式界面均使用这些公共组件。

## 验证与范围

页面遍历检查所有 58 个页面、19 个组件类别、5 个外层页签、窄窗口、重置及四种对照模式。实际指针/键盘验证覆盖 Switch、菜单、输入框、表单校验、评论、头像、历史、附件和弹窗；另以原生窗口检查桌面业务流程。

证据保存在 zork 的 `artifacts/storybook/design-completion/`，包括页面截图、交互结果、覆盖计划与交付记录。构建和原生测试日志见交付记录。

会话整页的 GPUI 一侧使用实际原生快照；历史、评论、附件等公共组件拥有独立可交互 Web 示例。原生完整会话的服务集成不在浏览器中模拟。移动端完整组件库与深色主题沿用独立范围。
