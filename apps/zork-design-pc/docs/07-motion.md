# 动效规范

动效服务于操作反馈与真实状态，不承担虚构进度，也不干扰阅读。

## 基础参数

| 场景 | 当前参数 |
| --- | --- |
| hover 反馈 | 120 ms |
| 普通过渡 | 180 ms |
| 缓出曲线 | `cubic-bezier(.2,.7,.2,1)` |
| 布局稳定 | 动画前后占位宽高不变 |

## 品牌联动提案

“图标轻碰 Z，字母依次响应”。当前样稿在 hover 时单次播放，不持续循环。

- 品牌图标：620 ms；最大水平位移约 3 px，转角约 −8°，最终回到原位。
- 字母：每个 440 ms；Z / o / r / k 延迟 90 / 140 / 180 / 220 ms。
- 字母最大响应约 `(2 px, −1 px)`；最后一个字母在约 660 ms 回到原位。
- 不改变侧栏宽度、导航位置和字标占位。
- `prefers-reduced-motion: reduce` 时保留静态标志。

字标本身仍在探索，因此动效也属于待评审参数。进入页面自动播放尚未作为当前规范确认。

## 工作状态

只有实际活跃且可见的执行状态可以使用循环动效。待验收、已完成、离线和未读以稳定静态状态为主。切换设备后停止不再可见的装饰动画。

## 验收

检查动画前后对齐、重复悬停、低帧率下的可理解性和减少动态效果。不能因为去掉动画就丢失运行、失败或需要处理的文字说明。

## 独立动效文件 v2

[查看标志动效源文件](../motion/linked.svg)

| 文件 | 用途 | 总时长 |
| --- | --- | --- |
| `motion/icon.svg` | 图标轻侧身，回到原位 | 680 ms |
| `motion/wordmark.svg` | 字母依次轻抬 | 675 ms |
| `motion/linked.svg` | 品牌图形靠近，字标依次回应 | 805 ms |
| `motion/icon-to-wordmark.svg` | 上半跳落，下半蠕动成 Z，再分开为 ork | 2000 ms |

图标下半块变成 Z，左上块保留左眼变成 o，右上块分开成为 r、k。0–240 ms 蓄力压缩并短暂眨眼，240–740 ms 沿弧线跳下，740–990 ms 柔软落地。分离使用圆润的短促弹开，不使用粘连或拉丝。

下半块在 820–1700 ms 向左蠕动成 Z，1010–1850 ms 上半块拉开为 ork，随后回弹收拢，2000 ms 静止。转换期间轮廓略圆润，静止后回到标准字形。每帧可见主体的横向中心保持在画布中线。

四个主体与两个眼部负形，每个轮廓都有 128 个对应顶点。主体在过渡中柔化边角，静止端点恢复标准轮廓。SVG 与原生 GPUI 共享 `motion/morph-points.json` 中的 91 个采样帧。Z 缺口保持同一轮廓上的三个顶点对应，预览可标出位置。

四种动画各自可播放、反向、慢速和拖动进度，不循环。减少动态效果时显示静态结果并关闭自动播放控件。浏览器 SVG 动效与原生实现分开验收。
