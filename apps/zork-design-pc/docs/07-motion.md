# 动效规范

动效服务于操作反馈与真实状态，不承担虚构进度，也不干扰阅读。

## 原则

动效只说明刚发生了什么、对象从哪来到哪去。多数动效在 200 ms 内结束；新的输入立即接管，从当前值继续，不等动画播完；从触发它的位置出现、回到那里消失。除“正在工作”外不做循环动效，不用弹跳。

## 基础参数

参数集中定义：桌面 `zork_ui::motion`，Android `ZorkMotion`；页面不写裸数字。

| 名称 | 数值 | 用途 |
| --- | --- | --- |
| 即时反馈 | 120 ms | 悬停、按下、开关、选中底色 |
| 标准 | 180 ms | 浮层、菜单、展开收起、分段选择、列表增删 |
| 表面 | 240 ms | 弹窗、底部弹层、状态提示 |
| 页面 | 280 ms | 手机页面进出；桌面内容区切换 150 ms 淡入 |
| 进入曲线 | `cubic-bezier(.2,.7,.2,1)` | 出现、落位 |
| 退出曲线 | `cubic-bezier(.4,0,1,1)` | 离开；退出时长为进入的 2/3 |
| 移动曲线 | `cubic-bezier(.3,0,.2,1)` | 已在屏上的对象换位置：滑块、分段、进度 |
| 手势释放 | spring 阻尼 0.9、中等刚度 | 底部弹层、返回手势松手后接着手速 |

## 场景

- 悬停与按下只改底色，不缩放、不位移、不改字重；Android 用按下底色代替水波纹。
- 开关滑块、分段选择的选中胶囊用移动曲线滑到新位置。
- 浮层、菜单、模型面板：从触发器一侧淡入，同时向外移动 6 px、从 0.98 放大到 1，缩放原点在触发器一侧；关闭只淡出。翻转方向时位移一起翻转。
- 弹窗：遮罩 200 ms 淡入，面板淡入并从 0.96 放大到 1；关闭时一起淡出，不缩小。开合中焦点与内容身份不变。
- 底部弹层：从底部滑入，拖动完全跟手，松手按手速弹簧收回或关闭。
- 展开收起：高度用移动曲线变化，内容在高度过半后淡入，箭头同步旋转；收起时内容先淡出。
- 列表增删与新消息：新行先撑开高度再淡入并上移 6 px；删除先淡出再收起。流式文字直接追加；阅读历史时来新消息不滚动，只淡入“回到最新”。发送不做飞行气泡，消息在 core 接受后才出现。
- 正在工作：柿色点 1.6 s 呼吸，只在确实运行且可见时播放；当前步骤换文字时 120 ms 交叉淡入。
- 加载：300 ms 内完成的不显示加载；超过才淡入骨架，出现后至少保留 400 ms。骨架只轻微呼吸，不扫光。
- 状态提示从所在区域上沿下移 8 px 淡入；可自行消失的 4 s 后淡出。数值变化用 300 ms 移动曲线补间，首次显示不播。
- 页面：手机进入从右侧 24 px 滑入并淡入，返回反向且手势跟手；桌面切页只让内容区淡入，侧栏与标题栏不动。
- 不做动效：键盘焦点环、悬停提示（400 ms 延迟后直接出现）、选中与未读状态切换、主题切换、附件增删、文字输入。

## 减少动态效果

跟随系统设置。去掉所有位移与缩放，只保留不超过 150 ms 的淡入淡出；循环动效改为静态；手势仍跟手，松手直接到位。去掉动效不丢失信息：运行、失败、需要处理都有文字。

## 性能

只动透明度、位移与缩放；展开收起的高度变化限定在单个容器内。静止、离屏和后台不申请帧。Zork Design 为带动效的状态提供重播与慢放 ×5。

## 品牌联动提案

“图标轻碰 Z，字母依次响应”。当前样稿在 hover 时单次播放，不持续循环。

- 品牌图标：620 ms；最大水平位移约 3 px，转角约 −8°，最终回到原位。
- 字母：每个 440 ms；Z / o / r / k 延迟 90 / 140 / 180 / 220 ms。
- 字母最大响应约 `(2 px, −1 px)`；最后一个字母在约 660 ms 回到原位。
- 不改变侧栏宽度、导航位置和字标占位。
- `prefers-reduced-motion: reduce` 时保留静态标志。

字标本身仍在探索，因此动效也属于待评审参数。进入页面自动播放尚未作为当前规范确认。

## 工作状态

只有实际活跃且可见的执行状态可以使用循环动效。待验收、已完成、离线和未读以稳定静态状态为主。切换设备后停止不再可见的装饰动画。

## 验收

检查动画前后对齐、重复悬停、低帧率下的可理解性和减少动态效果。不能因为去掉动画就丢失运行、失败或需要处理的文字说明。

## 独立动效文件 v2

[查看标志动效源文件](../motion/linked.svg)

| 文件 | 用途 | 总时长 |
| --- | --- | --- |
| `motion/icon.svg` | 图标轻侧身，回到原位 | 680 ms |
| `motion/wordmark.svg` | 字母依次轻抬 | 675 ms |
| `motion/linked.svg` | 品牌图形靠近，字标依次回应 | 805 ms |
| `motion/icon-to-wordmark.svg` | 上半跳落，下半蠕动成 Z，再分开为 ork | 2000 ms |

图标下半块变成 Z，左上块保留左眼变成 o，右上块分开成为 r、k。0–240 ms 蓄力压缩并短暂眨眼，240–740 ms 沿弧线跳下，740–990 ms 柔软落地。分离使用圆润的短促弹开，不使用粘连或拉丝。

下半块在 820–1700 ms 向左蠕动成 Z，1010–1850 ms 上半块拉开为 ork，随后回弹收拢，2000 ms 静止。转换期间轮廓略圆润，静止后回到标准字形。每帧可见主体的横向中心保持在画布中线。

四个主体与两个眼部负形，每个轮廓都有 128 个对应顶点。主体在过渡中柔化边角，静止端点恢复标准轮廓。SVG 与原生 GPUI 共享 `motion/morph-points.json` 中的 91 个采样帧。Z 缺口保持同一轮廓上的三个顶点对应，预览可标出位置。

四种动画各自可播放、反向、慢速和拖动进度，不循环。减少动态效果时显示静态结果并关闭自动播放控件。浏览器 SVG 动效与原生实现分开验收。
