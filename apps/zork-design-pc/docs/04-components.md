# 组件与交互

桌面控件的当前视觉基线为 [共享界面设计](../../../docs/design/interface.md)；[2026.09 控件记录](14-controls-revision.md) 是历史输入。交互示例在原生 `zork-design-pc` 中运行，与桌面客户端使用同一份 Rust/GPUI 组件。

Zork Design 的目录按产品区域分组（基础控件、对话、导航与新建、执行历史、设置与设备、首次使用、文件），组件下面直接列出它的状态；⌘K 按“组件 / 状态”搜索。总览把一个组件的全部状态平铺成当前主题的缩略图；单个状态是可交互的实时组件，顶栏在浅色与深色之间切换整个应用，并选择宽度（360、600、900 或窗口），检查面板列出交互状态、可读取的自动检查、自动化元素、源码与复制命令。一次只看一种主题，切换后缩略图按新主题重新生成。宽度是预设，不再把同一状态复制成窄屏与宽屏两份。应用记住上次位置，命令行参数优先。历史网页参考只作为归档素材保留。

## 侧栏导航（桌面）

移动端采用单屏导航和按压反馈，聊天列表没有持续 selected 背景，详见 [移动端规范](10-mobile.md)。

各设备的 Chat 按真实消息时间混排，并按日期分段；列表行标明执行设备。整行提供一致的 hover 和 selected 背景；active 只改变背景与文字颜色。

侧栏宽度可拖动并持久化，聊天页与设置页共享该宽度。窄屏样稿使用列表/内容切换；原生最小窗口行为仍需实际窗口验证，不能只用浏览器断点推定。

## 会话头与消息

会话头优先显示参与成员，弱化重复的大标题。显示已知人物的真实身份；时间与设备信息是辅助内容。

消息内容保留 Markdown 的段落、列表、代码与链接。工具运行过程在活动/执行历史中呈现，不把所有内部事件当作群聊消息。

## 选中文字评论

1. 在消息正文框选一段实际文字。
2. 浮窗显示所选原文，输入评论。
3. 添加到当前对话的评论队列。
4. 可继续选择其他片段、编辑或删除已有评论。
5. 在主输入框补充文字，一次发送整组评论。

评论必须保留来源消息、发言者和原文，不把所有批注拼成无来源的散句。浮窗添加评论不会立即发送；切换对话后原队列仍属于原对话。

## 输入框

随内容自动增高，无手动拖拽把手。达到 160 px 后内部滚动。附件、提及、发送入口保持紧凑；没有实际支持的操作要明确反馈，不能用样稿效果伪装上传成功。

输入、发送队列和已接收消息分开呈现。离线发送先进入本机队列，重连后按原设备和对话投递。

## 添加设备

使用统一导航入口打开添加设备流程；步骤围绕目标设备、安装/加入信息和可复制命令组织。手动方式始终是清楚可用的路径。展示命令模板不表示已经替用户安装或加入。

## 设置

左侧设置导航包括客户端、模型设置和设备设置。设备入口放在左侧，不在右侧重复生成一组主标签。

设备概览包含 Station 版本与设备能力；更新按钮以实际能力为准。

## 模型连接

顺序是 **订阅账号 / API 接入 → 供应商 → 连接名称与授权 → 连接详情 → 模型**。供应商用带图标的紧凑下拉，不把所有品牌按钮铺满表单。

连接创建后可以没有模型。获取模型必须调用真实支持的接口；手动添加需要明确模型 ID、协议与容量。模型容量遵循 `0 < 输出上限 < 上下文上限`。早期样稿允许相等是待修正差异，不是最终规范。

新 Chat 先选择执行设备，再选择该设备可用的模型、思考深度和可选连接。空连接显示“此连接尚未添加模型”，不得自动套入供应商预设。


## 原生弹窗布局 · 2026-09-06

弹窗采用一张连续的圆角面板。标题、内容和底部操作区之间不画分隔线，用留白区分层次；不使用网页式的头部/底部栏。标题左对齐，右上角用关闭图标；正文独立滚动，底部操作保持可见，按钮沿用 Zork 自有的圆角、配色和交互状态，不采用参考截图的胶囊按钮。浅色配色沿用 Zork 当前主题。

统一实现位于 `zork-ui::modal`，540 px 标准宽度、24 px 外圆角和左右内边距、20 px 标题。原生 `zork-design-pc` 的模型连接示例与客户端直接共享 Rust 实现；原始 HTML 样稿只作为历史输入。

按钮沿用原始 HTML `.button`：32 px 高、8 px 圆角、左右 14 px 内边距、12 px / 500 标签。主按钮使用炭墨色，次按钮使用浅色描边；禁用透明度 0.4，主按钮悬停透明度 0.9，次按钮悬停使用 hover 表面色。


## 开关 Switch · 2026-09-07

用于立即启用/停用一个布尔选项。轨道 41×24 px，滑块 18 px，左右内距 3 px；开启用语义绿色，关闭用中性描边色，禁用按 0.4 合成。交互区域为 48×32 px；轨道垂直居中，以较轻的视觉体量对齐 32 px 单行输入框、按钮和下拉框；Tab 聚焦，以背景反馈焦点，Space / Enter 切换。一个组件页签展示关闭、开启、禁用关闭、禁用开启和焦点五种状态。

模型连接、模型及协议选择器在触发器和选项行显示对应供应商图标；空值没有身份时显示占位文案。
