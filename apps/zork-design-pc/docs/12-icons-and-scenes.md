# 功能图标与 SVG 状态

## 功能 SVG 的圆角规则

本轮圆角调整针对功能图标；品牌主标志保持原轮廓。箭头、文件折页、立方体仍可以表达方向和几何关系，但端点、连接和外轮廓要尽量圆滑，避免尖刺感。

统一设计集采用 24×24 母版、约 1.7 的视觉描边、圆端点、圆连接。停止按钮采用圆角实心形，提示三角形的顶点直接使用曲线；不是只给 SVG 外层加圆角。

Apple 对 App icon 使用系统圆角遮罩的说明，不能直接等同于“所有功能符号都不允许几何转角”。SF Symbols 提供与文字配合的多种重量和尺寸；这里参考的是整体视觉一致性，圆润程度仍以 Zork 的实际尺寸检视为准。[Apple App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons)、[SF Symbols](https://developer.apple.com/sf-symbols/)。

## 完整原生资源清单

[原生 SVG 清单与引用位置](../assets/native/inventory.json)。实际图形可在 `zork-design-pc` 的“设计素材”目录查看。

清单分别扫描主代码目录和实现工作树，记录：文件、嵌入注册、直接 Rust 引用位置、来源与哈希。仅注册而没有直接引用证据，不等于永远未使用：动态路径需要另行判断。清单也不证明某个 SVG 此刻已经显示在运行中的界面里。

此前页面里的 70 个文件是设计提案材料，包含头像、品牌和插画，不是实际应用 SVG 的完整清单。当前设计集补入了实际使用的更多操作符号；原始原生快照单独保存，避免规范版本与实现版本混淆。

## 简洁 SVG 状态

界面状态直接复用 24×24 功能 SVG，在页面中以 20–32 px 显示。设备接入、离线、文件为空、收件箱为空、待验收、已完成分别使用对应的功能符号和文字，不再放置大幅装饰插画。

当前 SVG 状态在原生 `zork-design-pc` 的素材目录查看；[静态检视图](../previews/scenes-v2.svg)保留来源。对话首页保留已有品牌标志，移除重复插画。

旧场景和生成脚本保留在 `archive/scenes-v2/`；当前 `scripts/scenes.py` 仅复用功能 SVG。SVG 本身不判断运行状态，显示条件仍由真实业务状态决定。
