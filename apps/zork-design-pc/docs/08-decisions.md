# 决策与待定项

这份记录是当前规范的入口。归档文件保留当时的表达，不覆盖本页较新的决定。

## 已确认

| 决定 | 设计影响 |
| --- | --- |
| 产品名首字母大写 Zork | 新界面不使用早期小写字标 |
| Chat 按消息时间排列 | 列表标明执行设备，不设领队、队员或设备分组 |
| 新 Chat 在首次发送时创建 Session | 模型与思考深度属于 Session，不要求先创建 Agent 定义 |
| 选中文字后逐条评论，最后一次发送 | 评论浮窗不直接发送；队列按对话保存 |
| 统一桌面所有导航行 | 32 px 胶囊、同宽 hover / active，选中行悬停时加深 |
| active 与未读不改字重 | 避免点击后文字和布局抖动 |
| 去掉头像外圈，焦点用独立外环 | 柿橙焦点环画在轮廓外，不改变布局 |
| 输入框自动长高 | 无手动 resize 把手 |
| 侧栏固定像素、可拖动、保存宽度 | 聊天与设置一致 |
| 会话头收紧，头像左对齐 | 44 px 与共享消息列 |
| 模型连接保存在所属设备 | 新 Chat 选择执行设备及可用模型 |
| 接入方式优先，再选供应商 | 紧凑带品牌图标的下拉 |
| 连接后管理模型 | 新连接没有伪造的预设模型 |
| 本地预览 | 当前整理不包含部署或发布 |
| 平滑圆角 | 所有圆角为连续曲率；控件胶囊，卡片／浮层 24，大表面 32，气泡 24 带 8 折角 |
| 深色主题 | 与浅色共用语义 token，默认跟随系统；core 偏好 `theme` 可固定，桌面另有 `ZORK_THEME` |
| 设备标识 | 设备色块加折角，只表达身份；桌面侧栏设备坞，手机首页设备状态条 |
| Chat 行 | 桌面单行胶囊带设备标识；新建 Chat 在四台以内用设备标签，更多用下拉 |
| 消息完整显示 | 无消息折叠、折叠高度设置或全文页 |
| 执行历史像 agent session | Markdown 输出为主，工具调用安静单行，收发消息分开；无时间轴，桌面详情行内展开 |
| Chat 底部活动预览 | 只读投影成员 Session，不写入 Chat 消息 |

## 移动端已确认

移动端 nav7：导航与对话独占一屏；导航行 48 px；按压背景整行同宽；聊天列表不保留 active；底部两个入口并排等宽；从设备子页可直接返回原对话并保留草稿和阅读位置。此处是平台适配，不覆盖桌面的常驻当前对话状态。

## 当前方向

折角品牌图形、炭墨/暖纸/柿橙、轻量功能图标。历史消息的头像仍用于识别既有作者；平台各尺寸仍需检视。

## 仍待评审

- **定制字标**：不能只是普通字体排版；早期橙色块未清楚呈现折叠感；v2 改为轮廓折口，并保留回转候选。
- **品牌动画**：已提供图标、字标、联动、图标变名字四套 SVG 动效，细节随字标定稿。
- **宣传语**：中文与英文都是提案。
- **App icon**：已有 SVG 母稿与分层样张，尚未完成全部平台打包与尺寸验收。
- **场景插画**：已有素材，是否使用及摆放位置按实际页面决定。

## 已被替代

全小写 Inter 排版字标、选中导航的橙色竖条、靠加粗表达 active/未读、供应商全部平铺、连接时塞入模型预设、设置右侧重复主标签、各层级不同宽 hover、旧 task-first HTML、执行历史时间轴、消息折叠高度与全文页、手机工具连接设置、12 px 表单控件与 20 px 气泡等早期圆角。

## 2026-09-07 · 控件视觉更新

当时采用胶囊按钮、12 px 表单控件、32 px 弹窗与评论浮层、淡边框、20 px select 展开层；展开层加宽以保留选项留白并对齐内容。模型表单采用字段级错误提示，历史记录采用紧凑行。历史输入见 [控件视觉记录](14-controls-revision.md)，当前约束以 [共享界面设计](../../../docs/design/interface.md) 为准。
