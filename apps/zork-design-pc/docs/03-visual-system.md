# 视觉规范

桌面控件已更新为 [2026.09 确认版](14-controls-revision.md)：胶囊按钮、12 px 表单控件、32 px 弹窗与评论浮层，以及淡边框。

当前浅色工作区以 `tokens/design-tokens.json` 和交互样稿为依据。早期 `tokens.proposal.json` 已归档，不能直接覆盖当前布局、描边或字标规则。

## 品牌色

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 炭墨 | `#24272B` | 品牌主体、主文字、重要控件 |
| 暖纸 | `#F6F3EA` | 品牌背景、插画表面 |
| 柿橙 | `#E9643B` | 少量品牌强调、App 图标提案、字标探索 |
| 深柿橙 | `#B83C21` | 早期可读强调色提案 |

品牌色与 UI 语义色分别维护。橙色不代表任务失败、未读或网络离线，也不作为所有选中项的背景。

## 字体与文字

拉丁字符与数字使用 Inter Variable；中文使用 PingFang SC 或平台系统无衬线；代码使用系统等宽字体。素材目录保留字体文件和许可。

| 层级 | 当前基准 |
| --- | --- |
| 导航与控件标签 | 12 px |
| 会话正文 | 13 px，样稿行高 1.65 |
| 消息身份与时间 | 10–11 px |
| 常规说明 | 12–14 px |
| 设置页标题 | 22 px 级别，按实际页面层级使用 |

Leader、Task 可以有各自的基础字重；同一行的 default / hover / active / unread 之间不切换字重。品牌名用 **Zork**，不沿用早期全小写字标。

## 几何与密度（桌面）

移动端采用 48 px 导航行和触摸规范，见 [移动端差异](10-mobile.md)。本表不覆盖移动端。

| 项目 | 规范 |
| --- | --- |
| 单行控件高度 | **32 px**；输入框、下拉框、按钮、选项及图标按钮共用一个尺寸；Switch 的布局与点击区域等高，轨道 24 px 高、垂直居中 |
| 头像选择项 | 32×32 px 命中框，24 px 头像居中 |
| 间距阶梯 | 4 / 8 / 12 / 16 / 24 / 32 px |
| 常用圆角 | 按钮胶囊形；表单 12 px；下拉层与紧凑小卡片 20 px；独立卡片、内容面板与模态 32 px；内层反馈按外圆角和边距派生 |
| 侧栏 | 默认 240 px，拖动范围 200–420 px，持久化 |
| 侧栏拖动命中区域 | 6 px；分隔条不占用额外内容列 |
| 导航行 | 32 px，各层级与底部入口一致 |
| 设置 Agent 行 | 32 px，头像、名称、模型连接同一行 |
| 会话头 | 44 px |
| 内容列 | 默认最大 1000 px，宽屏 1040 px |
| 内容横向边距 | 默认 26 px；较窄窗口依次 22 / 18 / 12 px |
| 消息头像与顶部成员头像 | 26 px |
| 导航头像 | 20 px |
| 输入区域 | 内容高度 32–160 px；达到上限后内部滚动 |

顶部第一个成员头像与消息头像使用同一条左对齐线。品牌图标与下面设备/Leader 图标对齐。

## 边界与焦点

2026-09-10 更新：桌面导航的选中态改用左侧柿橙细短条，与 hover 背景分别滑动，具体以 `docs/design/interface.md` 的 `TabGroup` 规则为准。头像仍不添加 hover 外圈。保留确有分组作用的细边框、分隔线和弹层阴影。焦点用背景或控件自身状态反馈，不能把“去掉 outline”实现成没有焦点提示。
