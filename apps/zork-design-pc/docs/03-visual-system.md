# 视觉规范

桌面控件的当前颜色、圆角、尺寸、状态和焦点以[共享界面设计](../../../docs/design/interface.md)及 `zork-ui` 生产组件为准。Android 的触摸尺寸与系统输入见[移动端设计](../../android/design.md)。[2026.09 控件记录](14-controls-revision.md)保留早期设计输入，不覆盖当前实现。

## 品牌

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 炭墨 | `#24272B` | 品牌主体与重要文字 |
| 暖纸 | `#F6F3EA` | 品牌背景 |
| 柿橙 | `#E9643B` | 少量品牌强调 |

橙色不代表执行失败、未读或设备离线。品牌折角图形不承担作者身份或运行状态。

## 文字与密度

拉丁字符与数字使用 Inter Variable；中文使用 PingFang SC 或平台系统无衬线；代码使用系统等宽字体。正文、说明与辅助信息保持可读对比。同一行在 hover、selected、unread 之间不切换字重或尺寸。

桌面导航行使用 32 px 高度，侧栏宽度可在 200–420 px 范围拖动并持久化。Chat 按真实消息时间排列，行内标明执行设备。模型设置与设备设置有独立入口；不再提供 Agent 定义的创建、编辑或授权页。手机的 48 dp 行高和至少 44 dp 常用触摸区域见[移动端规范](10-mobile.md)。

## 形状与主题

控件是胶囊，容器按角色取大圆角，全部为连续曲率的平滑圆角；桌面由 GPUI 渲染器绘制，Android 由 Compose 形状绘制。浅色与深色主题共用语义 token，默认跟随系统。数值与规则见[共享界面设计](../../../docs/design/interface.md)，整体效果以 `zork-design-pc` 的「统一设计」总览为基线。

设备标识是设备色块加右上折角，颜色按设备名稳定散列，只表达身份；状态以形状加文字表达。

组件使用 GPUI 与 vendored 组件库的原生交互状态，Android 使用 Compose Material3。当前 token 由共享组件和 `Theme.kt` 持有；早期样稿中的数字不能替代生产控件的几何与验收。
