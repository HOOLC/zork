# Zork 设计资料

`zork-design-pc` 是原生组件与设计资料入口。交互示例直接运行与桌面客户端相同的 Rust/GPUI 组件；规范、可编辑素材、许可和历史参考保留在本目录中。

## 品牌

Zork 的标志以折角伙伴为中心。名称统一为 Zork，字标仍标为提案。炭墨 `#24272B`、暖纸 `#F6F3EA`、柿橙 `#E9643B` 是目前的视觉方向。人物、工作状态和供应商身份各有独立表达；12 个动物头像用于识别个体，外部供应商符号只识别服务。

原生组件目录中的品牌与动效示例可直接交互。素材目录保留 SVG、头像、字标候选和来源清单；细节见《视觉系统》《头像》《图标与场景》。

## 产品与 PC

设备 → Leader → Task 是长期协作与群聊式任务的层级。桌面导航行高 32 px、会话头 44 px、可调侧栏 200–420 px、输入框 32–160 px。页面与控件示例直接在原生组件区切换状态和窗口尺寸；早期网页原型只作为历史输入归档。

## 移动端

移动端保留相同的任务归属，但使用单屏导航、48 px 触摸行及适合单手操作的返回、选择和输入。移动端概念图和规范可在资料及素材区查看；浏览器窄屏不能代替原生 Android 验证。

## 素材与决策

素材区按品牌、头像、供应商、功能图标和状态图形浏览当前 SVG，历史设计截图单独标记。使用前核对素材清单中的状态、来源及许可证。规范 Markdown 是可编辑权威；旧网页仅作为历史参考保存，不再作为组件展示入口。
