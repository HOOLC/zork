# Zork 设计资料

`zork-design-pc`（Zork Design）是开发时的状态预览工具：一步到达某个组件的某个状态，并对照浅色、深色与不同宽度。示例直接运行与桌面客户端相同的 Rust/GPUI 组件和模拟数据；规范、可编辑素材、许可和历史参考保留在本目录中，不在应用内浏览。

## 品牌

Zork 的标志以折角图形为中心。名称统一为 Zork，字标仍标为提案。炭墨 `#24272B`、暖纸 `#F6F3EA`、柿橙 `#E9643B` 是目前的视觉方向。历史作者通过名称识别，执行状态和供应商身份各有独立表达；外部供应商符号只识别服务。

品牌标志与功能图标在 Zork Design 的「图标与品牌」中查看。素材目录保留 SVG、历史头像、字标候选和来源清单；当前界面约束见《视觉系统》《图标与场景》。

## 产品与 PC

Chat 按真实消息时间混排，并在行内标明执行设备；历史任务仍可读取。桌面导航行高 32 px、可调侧栏 200–420 px。页面与控件示例直接在原生组件区切换状态和窗口尺寸；早期网页原型只作为历史输入归档。

## 移动端

移动端沿用 Chat 与执行设备归属，使用单屏导航、48 dp 触摸行及适合单手操作的返回、选择和输入。移动端概念图和规范可在资料及素材区查看；浏览器窄屏不能代替原生 Android 验证。

## 素材与决策

素材区按品牌、供应商、功能图标和状态图形浏览当前 SVG，历史设计截图单独标记。使用前核对素材清单中的状态、来源及许可证。规范 Markdown 是可编辑权威；旧网页仅作为历史参考保存，不再作为组件展示入口。
