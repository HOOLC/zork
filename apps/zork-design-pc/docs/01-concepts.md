# 产品概念

Zork 以 Chat 组织人与执行 Session 的协作。用户选择执行设备、模型、思考深度和可选的模型连接，发送首条消息时创建 Chat 与独立 Session；后续消息继续进入该 Chat。创建新 Chat 不要求先创建 Agent 定义或配置领队授权。详见 [Chat 与协作](../../../docs/design/chat.md#navigation)。

## 界面中的对象

| 对象 | 含义 | 位置 |
| --- | --- | --- |
| 设备 | 执行与模型连接的归属地 | 设置与新建 Chat 的设备选择 |
| Chat | 可持续发送消息的协作频道 | 按真实消息时间排列的导航列表 |
| Session | 在所选设备上执行该 Chat 输入的上下文 | Chat 的执行状态与历史 |
| 模型连接 | 订阅账号或 API 接入及可用模型 | 模型设置 |
| 文件 | 消息附件与共享文件的固定版本 | 对话内容与文件入口 |

历史 Agent 定义、任务和消息保留原有身份及读取能力，不作为新工作的配置或导航层级。

## 品牌

折角、短横眼与双耳组成 Zork 的品牌形象。暖纸、炭墨和少量橙色让工作区保持克制。品牌图形不承担成员身份或执行状态。
