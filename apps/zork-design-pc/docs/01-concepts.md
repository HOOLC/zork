# 产品概念

Zork 把人与 Agent 的协作组织成能持续推进的对话和任务。人提出目标、补充判断、检查结果；Leader 负责组织工作；Worker 执行具体任务。设备承载真实的连接、配置与执行环境。

## 产品中的对象

| 对象 | 含义 | 在界面里的位置 |
| --- | --- | --- |
| Device / 设备 | 执行与配置的归属地 | 主导航顶层、设置中的设备父项 |
| Leader | 长期协作的组织者 | 设备下的独立对话；拥有自己的任务列表 |
| Worker | 接受具体委派的执行者 | 任务成员、设备的 Agent 管理；不作为平行聊天入口 |
| Task | 有目标、过程、结果与验收的工作单元 | 所属 Leader 下的群聊式任务入口 |
| Profile / 模型连接 | 某供应商、接入方式、凭据与模型配置的集合 | 目标设备 → 模型连接 |
| Model / 模型 | Profile 内可选择的一项执行配置 | 连接详情管理；Agent 设置里选择 |
| 文件 / 产物 | 工作过程中提交的内容与版本 | 对话内容和任务交付入口 |

## 信息架构

```text
设备 mini1
  产品 Leader
    安装体验改进
    设计规范整理
  工程 Leader
    客户端发布检查
设备 mini2
  研究 Leader
    竞品调研

设置
  客户端
  设备 mini1（概览）
    Agent
    模型连接
  设备 mini2（概览）
    Agent
    模型连接
```

同名 Agent 可以属于不同设备。所有选择、草稿、未读和设置都必须保留设备与对话归属，不能只按显示名称识别。

## 两种对话

**Leader 对话**是长期协作入口。用户提出新目标、询问进展、作出判断。

**Task 群聊**围绕一个具体任务展开，能看到参与者、明确的消息来源、评论和交付。任务评论交给所属 Leader 处理；Worker 是否返工由 Leader 根据任务决定。群聊布局不意味着所有成员都开放直接执行入口。

## 品牌概念：折角伙伴

双耳、短横眼和下方折口形成一个安静、机灵的小伙伴。暖纸和炭墨让工作区保持克制，少量橙色带来辨识度。折角隐喻“转向、接着做、交付”，不需要出现在每个控件上。

“让想法，有人接着做。”以及 “Ideas, carried forward.” 是早期传播文案提案，尚未确定为正式标语。

## 五类身份

品牌代表产品；角色图标代表职责；头像与姓名代表个体；状态标记代表正在发生什么；供应商图标代表外部服务。它们各有用途，不能互相替代。
