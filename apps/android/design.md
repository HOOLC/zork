# Zork Android — 当前界面基线

2026-09-24 按统一设计修订。延续移动端 nav7 的导航与对话分屏、48dp 整行触摸、44dp 独立操作区域、草稿和阅读位置保留；采用本轮确认的设置与控件修订。现有 nav7 静态原型只记录早期布局，不能覆盖本文件的新要求。

- 首页：各设备的 Chat 按消息时间混排，每行以 DeviceMark 标明所属设备；顶部设备状态条显示各设备在线状态。不按设备、创建者或角色分组，不提供领队／队员管理入口。内部 API 标识不翻译。
- 新建 Chat：只有一个悬浮入口；设备选择在新建页内以设备标签切换。新建页复用 Composer 与模型、思考深度选择控件；连接（Profile）可选，默认自动，只列出提供所选模型的连接；首次发送前只有 core 草稿。
- 对话头部：成员入口打开该成员的执行历史；「更多」收纳文件与归档。
- 消息始终完整显示，不折叠、不设折叠高度，也没有单独的全文页。
- 视觉：复用共享 Zork 字体和资源；Inter 400/500/600，中文系统字体。暖纸背景、炭墨正文；主操作用墨色，柿色只表达工作中／发送中；绿色只表达在线或已验证，琥珀色表达待验证。状态同时以形状和文字表达，不只靠颜色。
- 颜色真值：`Theme.kt`，浅色与深色两套调色板对齐共享 `zork-ui`；不在页面临时创建近似色。
- 几何：控件使用胶囊，容器 24dp 圆角，底部表单上角 32dp，消息气泡 24dp；底部表单主操作占满内容宽度。Composer 采用静态圆角面板和细描边，外层留白 12dp；输入最多显示三行，更多内容在编辑器内部滚动。触摸区域至少 44dp，文字不小于 12sp，不套用桌面 32px 命中尺寸。
- DeviceMark 以设备色块加折角表示设备身份，颜色与桌面按同一散列取值，只表达身份不表达状态。
- 设备卡片集中名称、改名图标、连接与版本信息。手机无法修改的运行方式与登录启动不展示；后端不支持或设备离线时隐藏整个更新区，不摆灰色占位按钮和说明入口。
- 设置、设备和大模型列表不显示装饰性右箭头。
- 大模型页展示提供商标识、连接名、接入方式、模型数和验证状态。订阅授权与 API Key 分开；新连接不生成假模型。支持手动配置和获取模型 ID；未知 token 上限由用户填写，不伪造。
- 输入采用有标签的字段；秘密仅存在当前表单内存，不进入状态快照或调试输出。保存时禁用重复提交，错误留在表单中，成功后刷新所属设备。
- 旧 home 仍作为历史 Chat 可打开。
- 应用模态弹窗统一从底部呈现，包括确认、提示、编辑和详情；宽屏也保持贴底，键盘升起后贴合可用区域底边。使用不透明表面与系统遮蔽，无背景模糊，不依赖 hover；支持系统键盘、滚动、返回关闭，并将焦点交还各自的来源。
- 消息立即进入列表；超过一秒未 ACK 才显示发送中；失败手动重发／删除，不自动重试。重连按历史游标补齐，消息快照按变化更新。

验收使用生产 Compose 组件，在 320、375、414、768dp 宽度验证布局；底部表单必须采集其实际窗口，不能用底层 Activity 的截图代替。

## Session 执行历史

- 对话头部成员入口和输入区成员状态入口各自打开对应成员的执行历史；成员入口保留互不重叠的 48dp 触控区域及完整读屏名称。
- 执行历史读起来像该成员的 agent session：模型输出以 Markdown 为主体；工具调用是安静的单行记录；收到的消息与发出的消息各有区分的样式；等待与错误独立成行。不提供时间轴、缩放、平移或选区。
- 长输出在列表内预览，完整内容通过「查看全文」进入详情。详情为 32dp 上角的底部表单，支持系统返回、完整内容复制及原始事件 JSON 展开。
- 分组、对象解析、用量和记录生命周期均来自 Rust core；Compose 只维护展开、滚动、焦点等呈现状态。当前验证与数据边界见 [Session history](../../docs/design/execution-history.md#android)。

## 客户端设置

- 正式入口与截图预览共用透明系统栏和全屏页面背景；状态栏与底部导航栏下方跟随当前页面颜色，内容在安全区域内排布。

- 设置分三组：「客户端」含账号、外观、通知和已归档的 Chat（首页不再有归档入口）；「Mesh」含模型连接（全局，按提供商）、设备和连接设备；「高级」含安卓调试和清空本机数据，清空前以底部表单确认。没有「工具连接」，不设置「这台手机」和日常身份标识入口。逐项实现范围见 [设置对齐记录](../../docs/design/interface.md#mobile)。
- 外观只提供主题：跟随系统、浅色、深色。选择保存在共享 core 客户端偏好的 `theme`，只应用于这台手机。字号跟随系统，不提供额外字号选项。
- 通知提供接收开关、会话名称隐私、声音、当前会话免打扰、系统权限与测试通知。后台保持连接默认关闭；开启后显示系统要求的常驻通知，系统停止应用后需重新打开。

## 设备设置与 PC 对齐

- 模型连接列表使用连接显示名称、提供商与验证状态，以及共享 core 归一化后的真实额度；没有额度数据不显示伪造的余额或百分比。详情支持重命名、刷新额度、更新模型及手动添加。
- 模型列表按可见项构建，显示上下文／输出上限和启用开关；缺少容量配置的模型不可直接启用。编辑支持从已有模型复制配置、K/M 容量输入、行内错误、图片读取能力和移除模型；复制不更改目标模型的 ID、默认／启用状态。
- 模型表单的操作区固定在底部，字段可独立滚动；键盘升起后仍能保存或关闭。
- 操作通过共享 core 的设备请求与设置投影收敛，UI 不建立第二份持久业务列表。离线继续呈现缓存，失败保留表单输入。
- 设备服务提供状态、详情及日志。沿层级返回，保留原表单。
- Mesh 的「连接设备」让手机通过扫码或粘贴电脑邀请接入已有设备；生成邀请、批准其他设备和节点接入命令留在电脑端。设置不提供「帮助与诊断」或「关于 Zork」入口。
- 设置操作与升级按 core 的操作标识恢复；非敏感输入和选中记录可跨界面重建恢复，秘密输入不进入 Android 保存状态。长表单固定主操作区。

## Composer 执行状态

- 活动 Session 以静态胶囊显示名称和状态，完成后保留“空闲” 1.2 秒再归位。
- 色彩取当前主题的 Paper、FieldBorder 和 Ink；工作中以柿色表达。Surface、平滑圆角形状和 Material3 控件负责填充、描边及裁切。
- 执行状态与消息底部占位使用当前状态的同一布局，跟随尾部时消息同步避让，浏览历史时保持阅读锚点。

## 文件

- 附件按钮打开「添加到草稿」底部表单：照片（系统照片选择器，不申请相册权限）、拍照、文件（系统文件选择器，任意类型）。所选文件先复制到私有缓存，再交给 core 固定为草稿快照，副本随即删除；文件属于选取时的对话。
- 草稿文件是编辑区上方一排 48 dp 胶囊（同心的 40 dp 缩略图、名称、大小、44 dp 移除），横向滚动、右缘渐隐，不与编辑器滚动嵌套。读取中显示进度，失败在胶囊上写明原因；仍在读取时不能发送。点胶囊预览草稿内容。
- 消息里的图片保持比例（多张为两列网格），其他文件是 16 dp 圆角文件块：类型标记、名称、大小或当前状态，保存是独立的 44 dp 按钮。点击即预览；来源设备离线或已吊销时写明原因，不显示占位内容。
- 预览是全屏暖灰画布：图片可缩放和平移，同一消息的文件可前后切换；保存与“用其他应用打开”在更多菜单里。类型标记、大小、缩略图资格、字节校验与授权都来自 core，界面只解码和展示。
- 性能回归使用 `ComposerPerformanceTest.presenceFrames` 记录真实状态切换的完整帧；模拟器和真机结果分开，不把静态界面人为推进成连续动画。

## 与统一组件规范的关系（2026-09-09）

通用视觉语义与状态契约见 [已确认设计规范](../../docs/design/interface.md) 及 [组件交互契约](../../docs/design/interface.md#interaction)。本文件继续负责手机布局、44/48dp 触摸区域、底部表单、系统返回与 IME；桌面图标按钮的 28/32px 尺寸不适用于触屏。

共享规则按组件家族对照到 `Theme.kt` 与 `SettingsControls.kt`；不同 token 先确认语义和平台理由，再迁移实现。当前 PC 表单批次不代表 Compose 已完成对应变更或验收。
