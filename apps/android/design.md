# Zork Android — 当前界面基线

2026-09-07。延续移动端 nav7 的导航与对话分屏、48dp 整行触摸、44dp 独立操作区域、草稿和阅读位置保留；采用本轮确认的设置与控件修订。现有 nav7 静态原型只记录早期布局，不能覆盖本文件的新要求。

- 名称：设备 → 领队 → 任务；设置入口为「队员」「大模型」，队员页内按领队／队员分组。内部 API 标识不翻译。
- 视觉：复用共享 Zork 字体和资源；Inter 400/500/600，中文系统字体。暖白背景、白色内容、炭墨正文，绿色只表达在线或已验证，琥珀色表达待验证。
- 颜色真值：`Theme.kt`，与共享 `zork-ui` 的 Paper、Muted、Border、FieldBorder、Online、Warning 对齐；不在页面临时创建近似色。
- 几何：设置卡片 20dp 圆角、输入框 12dp、底部表单上角 32dp，按钮使用胶囊，底部表单主操作占满内容宽度；消息气泡 20dp；Composer 采用与桌面一致的暖白实色液态轮廓和共享细描边，外层留白 12dp；输入最多显示三行，更多内容在编辑器内部滚动，单行主体紧凑至 88dp（不含伙伴突出区域）。移动端保留至少 44dp 触摸区域，不套用桌面 32px 命中尺寸。
- 设备卡片集中名称、改名图标、连接与版本信息。手机无法修改的运行方式与登录启动不展示；后端不支持或设备离线时隐藏整个更新区，不摆灰色占位按钮和说明入口。
- 设备下直接列出 Chat 并提供新建入口。新建页复用 Composer 与模型、思考深度、Profile 选择控件；Profile 可选，首次发送前只有 core 草稿。设置、设备和大模型列表不显示装饰性右箭头。
- 大模型页展示提供商标识、连接名、接入方式、模型数和验证状态。订阅授权与 API Key 分开；新连接不生成假模型。支持手动配置和获取模型 ID；未知 token 上限由用户填写，不伪造。
- 输入采用有标签的字段；秘密仅存在当前表单内存，不进入状态快照或调试输出。保存时禁用重复提交，错误留在表单中，成功后刷新所属设备。
- 导航中的 Chat 直接显示，不按创建者或角色分组；旧 home 仍作为历史 Chat 可打开。
- 应用模态弹窗统一从底部呈现，包括确认、提示、编辑和详情；宽屏也保持贴底，键盘升起后贴合可用区域底边。使用白色不透明材质与 55% 黑色遮蔽，无背景模糊，不依赖 hover；支持系统键盘、滚动、返回关闭，并将焦点交还各自的来源。
- 消息立即进入列表；超过一秒未 ACK 才显示发送中；失败手动重发／删除，不自动重试。重连按历史游标补齐，消息快照按变化更新。

验收使用生产 Compose 组件，在 320、375、414、768dp 宽度验证布局；底部表单必须采集其实际窗口，不能用底层 Activity 的截图代替。

## Session 执行历史

- 顶部成员头像和输入区成员状态入口各自打开对应成员的 Session；成员停靠区使用互不重叠的 48dp 触控区域，头像与标签共用一个读屏操作。
- 采用共享语义图标、两行记录、常规操作折叠组和独立的等待／错误记录；组展开状态在前插历史后保留。对象名称是独立链接，点击不穿透到记录详情。
- 列表、紧凑模型／用量概览和三轨时间轴分区；时间轴支持缩放、平移、选区和完整记录选择器。模型请求通过时间轴查看，记录选择会展开对应组并定位。
- 时间轴遵循 PC 的独立视觉语义：输入蓝色、模型紫色、工具绿色、失败红色；实心细条、11dp 基础轨道、上方刻度和灰色圆点断点，不使用列表的灰黑配色或网格。手机的缩放／选区按钮收进底部操作菜单，记录选择与详情保留 44dp 点击区域。近距离缩放显示毫秒，纯瞬时事件保留真实时间间距，绘制与点选共用裁剪几何。
- 详情为 32dp 上角的底部表单，支持系统返回、分段选择、完整内容复制及原始事件 JSON 展开。大字号下底部概览和时间轴独立滚动，为记录保留阅读区域。
- 分组、对象解析、用量、额度和记录生命周期均来自 Rust core；Compose 只维护展开、选区、滚动、焦点等呈现状态。当前验证与数据边界见 [Session history](../../docs/design/execution-history.md#android)。

## 客户端设置

- 正式入口与截图预览共用透明系统栏和全屏页面背景；状态栏与底部导航栏下方跟随当前页面颜色，内容在安全区域内排布。

- 首页提供「工具连接」「外观」「通知」，设备管理保留独立分组；不设置「这台手机」和日常身份标识入口。逐项实现范围见 [设置对齐记录](../../docs/design/interface.md#mobile)，不以早期“已对齐 PC”的描述代替当前功能核对。
- 外观提供消息折叠高度：拖动示例消息底部横线，松手保存；可恢复自动，手动范围为 80–720dp。配置保存在共享 core 的本地客户端存储，只应用于这台手机；自动值为稳定的 192dp，键盘收放不重新截断消息。字号跟随系统，不提供额外字号选项。
- 通知提供接收开关、会话名称隐私、声音、当前会话免打扰、系统权限与测试通知。后台保持连接默认关闭；开启后显示系统要求的常驻通知，系统停止应用后需重新打开。深色外观仍待完整主题实现。

## 设备设置与 PC 对齐

- 模型连接列表使用连接显示名称、提供商与验证状态，以及共享 core 归一化后的真实额度；没有额度数据不显示伪造的余额或百分比。详情支持重命名、刷新额度、更新模型及手动添加。
- 模型列表按可见项构建，显示上下文／输出上限和启用开关；缺少容量配置的模型不可直接启用。编辑支持从已有模型复制配置、K/M 容量输入、行内错误、图片读取能力和移除模型；复制不更改目标模型的 ID、默认／启用状态。
- 模型表单的操作区固定在底部，字段可独立滚动；键盘升起后仍能保存或关闭。
- 操作通过共享 core 的设备请求与设置投影收敛，UI 不建立第二份持久业务列表。离线继续呈现缓存，失败保留表单输入。
- 工具连接提供工具及参数详情，设备服务提供状态、详情及日志。沿层级返回，保留原表单。
- 手机通过扫码或粘贴电脑邀请接入已有设备；生成邀请、批准其他设备和节点接入命令留在电脑端。设置不提供「连接其他设备」、「帮助与诊断」或「关于 Zork」入口。
- 设置操作与升级按 core 的操作标识恢复；非敏感输入和选中记录可跨界面重建恢复，秘密输入不进入 Android 保存状态。长表单固定主操作区，头像提供中文可访问名称及选中语义。

## Composer 伙伴状态

- 停靠头像使用共享 `avatars/portraits` 原始路径；活动伙伴从停靠列展开为带名称和状态的胶囊。
- 色彩为 Paper `#F6F5F1`、FieldBorder `#DEDFDF` 和 Ink `#24272B`；填色与描边来自同一个完整轮廓，不绘制内部接缝。
- 使用临界阻尼弹簧，目标变更保留速度；完成后显示“空闲” 1.2 秒再归位，静止时停止动画，遵循系统动画缩放设置。
- 伙伴与消息底部占位消费同一帧的位移；跟随尾部时消息同步上移，浏览历史时保持阅读锚点。附件使用独立滚动区域，不与编辑器滚动嵌套。

- 复用跨端液态几何与视觉状态，CPU 计算轮廓、GPU 绘制实色填充与描边；缓存不变几何，不逐帧生成位图遮罩。共享边界按 [液态合同](../../docs/design/interface.md#liquid) 执行。
- 性能回归使用 `ComposerPerformanceTest.presenceFrames`，保留设备实际像素密度，在固定对话上比较完整帧、布局、绘制与 GPU 耗时；不能用低密度模拟器的局部绘制时间代替真机结果。

- 会话优先请求设备支持的 120Hz 模式；动画仅在布局／绘制阶段读取进度，输入控件与伙伴区域分别测量。消息列表在状态切换时安排底部空间，动画帧只移动已排版的消息区域，并保留上方缓冲行，避免重复排版或露出空白。
- 状态标签复用测量结果，草稿控件、消息预览与伙伴状态分别更新。真实呈现以 FrameTimeline 验证，CPU UI 预算为 8.33ms；模拟器结果与真机结果分开。

## 与统一组件规范的关系（2026-09-09）

通用视觉语义与状态契约见 [已确认设计规范](../../docs/design/interface.md) 及 [组件交互契约](../../docs/design/interface.md#interaction)。本文件继续负责手机布局、44/48dp 触摸区域、底部表单、系统返回与 IME；桌面图标按钮的 28/32px 尺寸不适用于触屏。

共享规则按组件家族对照到 `Theme.kt` 与 `SettingsControls.kt`；不同 token 先确认语义和平台理由，再迁移实现。当前 PC 表单批次不代表 Compose 已完成对应变更或验收。
