# Shared resource origins

Central Icons and the Inter variable font were supplied from the company-owned
`AFK-surf/Cue` repository at commit `ac54574a3` (2026-09-05), under the product
owner's resource-sharing authorization. This records provenance only; no source
checkout, account service or build step depends on that repository.

The original Central Icons package names and exports are retained in
[Central-Icons-sources.json](Central-Icons-sources.json). Stroke normalization
from 2 to 1.5 is part of the imported masters. Company resource authorization
for these icons is separate from the Inter SIL Open Font License, retained
alongside the font files. Original font bytes and family names are unchanged.
