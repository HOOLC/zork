# 圆角、描边与裁切

尺寸与形状按 [界面设计](../../../docs/design/interface.md)。液态与平滑轮廓复用 [zork-liquid](../../../crates/zork-liquid/src/lib.rs)，普通静态圆角沿平台原生绘制。SVG 内部造型另用 [图标 skill](../zork-svg-icons/SKILL.md)。

## 选择与几何

- 先选控件语义和现有尺寸变体；同体量的独立卡片与浮层共用容器档位，静态选择浮层按下文例外。贴边内层反馈从外圆角与内边距派生。胶囊、圆形、字段和紧凑小卡片保留各自比例；Android 保留 [触摸几何](../../../apps/android/design.md)。不为换圆角另造一套控件。
- 半径与平滑度分开。连续圆角不能用增大普通 radius 冒充；复用 `liquid::rounded_rectangle` 的 Bézier 构造、边长预算与来源许可，不在页面或平台重写近似公式。
- 静态表面不启动物理模拟；形变使用既有 `Simulation` / `Surface`。当前合同为平滑矩形和圆形，其他形状需单独定义和验证。
- 动态圆角检查最终轮廓而非只读目标 `Pose.r`；速度引起的额外圆化按像素限制，矩形面板不能在高速开合中变成椭圆。
- 输入须有限，半径非负，平滑度在 `[0,1]`。`Pose` 宽高至少为 2，隐藏/零尺寸由调用层处理；短边不足时由共享几何收敛半径和平滑度，不强塞过渡区。

## 绘制与缓存

- 填充、描边、焦点和精确命中共享当前几何；内容在轮廓内，界面不绘制阴影。细描边沿外轮廓向内绘制，孔洞朝材料一侧；复用共享细分与连接，不用不同半径叠出接缝。焦点颜色替换同一描边，避免重复叠画抗锯齿边缘。热区与业务状态不随微小形变漂移。
- 静态背景不是内容掩码，内容需内边距/内层滚动约束。填充、反馈/内容、描边依次绘制，嵌套控件的轮廓外保持透明。父底色遮盖只适用于能确认平坦同色的画布，不能充当通用裁切；透明、渐变或图像背景需真实路径掩码。无框预览只提供矩形视口。
- 窗口浮层可保留外部透明，并用 `Surface::inset_content` 将内容限制在当前轮廓内的保守矩形视口。它按同一条曲线排除边界交叉，不是任意路径掩码；内容满铺到形变边缘仍需相应裁切适配。内容独立缩放应作用于绘制，保持原布局，并在变换后按实时轮廓裁剪；缓存重放及渲染回退均须保留当前路径掩码，不能重复变换、沿用旧掩码或退化成其外接矩形。不能用普通圆角或终态尺寸约束正在变化的表面。
- 保守裁切按实际内容范围选择：模态分头部、正文与操作区，不能让最圆的角切掉整个中段。固定宽度下的测量与绘制复用同一份布局，测量更新经已有帧调度重定目标，避免重复布局导致尺寸或焦点身份分叉。 触发器的输入与焦点槽留在内容掩码之外，精确命中仍由表面几何约束；透明退场内容不拦截再次激活。
- 仍在形变的紧凑菜单用 `Surface::content_clip` 保持文字布局，裁剪文字/图标所在的带状区域，并将选项底色与当前轮廓求交；不要把整块保守矩形视口用于所有行，也不在形变中触发省略。它不提供富文本、输入框或图像的通用路径掩码。
- 普通下拉与模型选择面板使用 16 px（手机 16 dp）普通圆角，填充、描边和阴影共用轮廓；6 px 内缩的选中行用 10 px 圆角，不借用形变掩码。
- 短标签的轮廓内外反色共用固定文字布局，按实时轮廓划分两种墨色，允许一个字被部分覆盖；不能按选中索引整段切色，也不能用保守矩形裁切代替实际曲线。
- 分区先排除不相交几何，仅在穿过分界时切分；裁剪带不能反复上传整条路径，剔除不可能影响可见区域的三角形时保留抗锯齿余量。
- 稳定组件/材料身份驱动缓存；尺寸、半径、平滑度与材料改变时失效，仅位置变化复用几何。中断从当前状态接续，静止/离屏停帧；已收起且静止的屏外来源随新布局同步，重新进入时轮廓与热区一致。减少动态效果直接到目标。

## 验证

只改本次受影响控件，展台已有实现不表示生产已迁入。几何从 [共享测试](../../../crates/zork-liquid/src/tests.rs) 覆盖零半径、短边、大半径、胶囊/圆形与尺寸变化，检查闭合、连续、有限、无自交及边界命中；平台描边和裁切另验实际绘制。

绘制用原生 `headless_modals` 与 [设计应用测试](../../../scripts/design-pc/test_native_workbench.py) 检查四边、闭合圆角、焦点和向内占位；动态裁切用 [原生逐帧检查](../../../scripts/design-pc/test_native_liquid_clip.py) 对照中间帧与实时路径，检查来源文字、反向和命中，另测停帧。共享接入按 [UI parity](../zork-ui-parity/SKILL.md)，检查入口按 [验证规则](../zork-validation/SKILL.md)。
