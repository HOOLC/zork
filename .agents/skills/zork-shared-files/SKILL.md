# 聊天附件

先读 [附件合同](../../../docs/design/shared-files.md)。产品已移除共享目录与 Agent Skill 分发，文件交付沿消息或任务的实际归属处理。

- 引用绑定来源、哈希与大小。完整保存并验证后才发布源消息；同名新文件不改变旧引用。接收端经 iroh 向授权来源读取固定内容，不启动目录扫描或元数据同步。
- core 拥有预览、保存、取消、缓存与权限失效；平台只提供呈现和保存目的地。缓存不能绕过授权，撤权或连接代次更换拒绝迟到结果。
- 只维护当前身份和附件存储；不增加 Synch 旧库读取、迁移或旧协议适配。代码清理不自动删除设备上的历史数据。
- 按 [验证规则](../zork-validation/SKILL.md) 检查固定版本、损坏内容、撤权与当前身份持久化。真实 Android 展示和系统导出另行验证；同机双节点不证明物理跨网。
